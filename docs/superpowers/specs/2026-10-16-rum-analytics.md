# RUM 基础统计与功能打点

## 目标与边界

使用阿里云 CMS2.0 RUM 中国区，统计基本使用量和少量功能使用次数，不做留存、用户画像、广告归因或会话回放。2026-10-16 已用 macOS 官方 SDK 验证大陆电信直连的单条自定义事件进入上海 SLS。该结果不代表所有运营商或四端均已验证。

账号所有者已确认设置 `1 OCU/天` 限额；这是人工确认，不是当前 API 回读结果。不要修改其他云产品、限额或 RAM 权限，不在客户端放 AccessKey。

## 用户控制与隐私

- 2026-10-17 起四端默认开启（用户决定）：没有存过选择即视为开启；用户明确关闭后保持关闭。存储损坏或读不出时保守关闭并提示。SDK 启动/停止等故障只让当前进程不可用，不改写用户的同意值。
- 活跃设备数用本机随机生成的安装标识（UUID v4）作为 SDK 设备标识，不读取硬件编号、IMEI、MAC、Android ID 等；用户关闭统计时删除，重新开启后生成新的。界面说明这一点。
- 在现有“关于”窗口放统计开关；iOS 增加原生隐私设置入口。说明提供方是阿里云、数据存储在中国大陆，并披露设备、系统、网络/IP、地区、会话信息可能由 SDK 自动采集。
- 关闭后立即阻止新事件，停止 SDK，清理本地待发缓存及统计标识。已经发出或进入网络传输的请求无法撤回。
- 不采集照片、预览、文件名/路径、EXIF、照片/外观身份、账号、AI 提示词、AI 地址/Key 或原始错误文本。关闭网络拦截、崩溃、自动交互、回放和 SDK 自监控等非必要模块；无法证明关闭能力的 SDK 不启用。
- 不重写未公开的 RUM 上传协议。SDK 缺失、未配置、初始化失败或分发许可未确认时，不影响照片编辑，明确显示尚不可用，不伪装成已上报。

## 事件契约 v1

事件名和分组不随界面语言变化；分组固定 `usage`，附加字段固定 `schema_version=1` 和 `platform=macos|ios|android|windows`。

| 名称 | 时机 | value | 额外字段 |
| --- | --- | --- | --- |
| `app_started` | 每次进程启动且获准启用后一次 | 1 | 无 |
| `photo_imported` | 用户导入并成功得到可用预览 | 1 | 无 |
| `film_selected` | 用户点击外观选项且选择确实改变；不包含导入后的自动选中、恢复编辑或程序赋值 | 1 | `kind=none|built_in|custom` |
| `export_completed` | 单张文件/Photos 发布确实成功 | 1 | 无 |
| `batch_export_completed` | 一次批量运行进入终态，不在重绘/恢复中重复发送 | 本次成功数 | `outcome=completed|partial|cancelled|interrupted`，`succeeded_count`，`failed_count` |

不提供接受任意名字、任意字典的业务打点入口。计数为非负有界整数。批量重试记录本轮增量，不重复累计已有成功项。后台/关窗不是成功导出。
外观文件导入本期不单独统计；自动应用导入结果不冒充外观选项点击，四端保持同一口径。

## 架构与发布门槛

统计放在客户端业务层，不进入 C++ 渲染核心。优先共享 Swift 契约和同意控制；Kotlin/C# 使用等价强类型契约。传输通过小型可注入适配器，便于无网络测试。事件分发不阻塞编辑/渲染线程，不无限重试，不缓存关闭期间的事件。

四端各自使用对应平台应用配置，测试和正式环境区分。仅公开 AppID/ServiceID、ConfigAddress/Endpoint、Workspace 等接入参数；RAM 凭证只用于操作者 API 工具。

2026-10-17 用户决定正式包带上 SDK，并由其负责确认供应商 SDK 的再分发许可：

- 正式/分发构建（macOS `build.sh`、Windows Release、Android release、iOS Release）默认带 SDK，以 `env=PROD` 上报到现有四个云端应用；调试构建默认不带，开发运行不进入正式数据。正式构建可显式出不带 SDK 的包（`RAWLAB_RUM=0`、`-NoRumSdk`、`-PrawlabRum=false` 等），各端打包检查核对带与不带。
- SDK 二进制不进仓库：按版本放在主工作区 `.cache/shared/aliyun-rum/`，从供应商带版本号的公开地址下载，SHA-256 固定，不符即停止构建。
- 正式上报目标写死在应用里；环境变量只能追加合成验证标记 `validation_run`，不能改写目标。显式本地验证构建（`env=LOCAL`、独立包名与同意存储、目标来自环境变量）保留。
- 实网验证每端只发送 5 条带随机标记的合成事件，并另行核对正式包真实启动事件与安装标识；不使用真实照片。

## 验收

证明从未选择时默认开启并只计一次启动、明确关闭后不初始化/不发事件、关闭时删除安装标识、配置失败不影响编辑、固定事件无敏感字段、失败/取消不计作成功、重试计数正确。执行各平台可用的编译/测试；没有设备/工具链的项目明确记为未验证。云端验证只发送有界合成事件，不使用真实照片或个人设备名称作为业务字段。
