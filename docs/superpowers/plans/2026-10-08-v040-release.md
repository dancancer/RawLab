# RawLab v0.4.0 Release Plan

**Goal:** Publish the verified Windows handoff and refreshed Mac/Android packages after merging the existing feature branch into `main`.

**Scope:** Release metadata, bilingual download documentation, release notes and package verification. Preserve the supplied Windows archive and its historical build provenance; do not claim that it was rebuilt as assembly version 0.4.0. Keep iOS downloads explicitly at v0.2.

1. Pull the existing branch and validate the Windows archive against its committed manifest, including ZIP integrity, licenses and build provenance.
2. Set Mac/Android versions to 0.4.0, build number 5. Update root/platform READMEs and release notes with accurate feature and artifact boundaries.
3. Rebuild both macOS 15 architectures and the release-signed Android APK. Run relevant core, application, package, signature and upgrade checks. Keep fresh results separate from the Windows handoff's recorded runtime results.
4. Package verified applications, corresponding LibRaw source archives and SHA-256 checksums. Exclude private RAW files, Adobe profiles and signing credentials.
5. Commit and push owned changes, create and attach a PR targeting `main`, then merge without bypassing protections. Verify the resulting remote commit.
6. Create v0.4.0 from the merged commit, upload the checked assets to a draft release, verify uploaded metadata, and publish. Confirm the release and download links.

**Constraints:** Windows cannot run on this Mac. Mac packages remain ad-hoc signed and not notarized; macOS 15 hardware and native Intel hardware are not available. Android emulator checks do not certify every physical device. No CI success will be claimed where the repository has no configured checks.

**Validation finding:** Enabling the external portrait Sony fixture exposed an existing `raw_smoke` reference-index bug: the reference pixels remained in sensor orientation, while the application output was rotated. Correct only the test mapping, preserve the tolerance and production pipeline, and rerun both architectures with Sony and DJI fixtures.
