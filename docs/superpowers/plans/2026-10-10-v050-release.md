# RawLab v0.5.0 Release Implementation Plan

**Goal:** Publish the current `development` code as v0.5.0, with introductory
English/Chinese READMEs, a separate changelog and GPLv3 licensing.

**Architecture:** Work from `origin/development` in an isolated worktree. Keep
the dirty original checkout untouched. Use the existing platform build scripts
and signing identities; rebuild all client code and native libraries.

**Tech Stack:** C++17/LibRaw, Swift/Xcode, Kotlin/Gradle, WPF/.NET/MSVC.

**Spec:** The user's release request in this chat.

## Constraints

- Version `0.5.0`, build `8`; existing minimum OS requirements are unchanged.
- English `README.md` and Chinese `docs/README.zh-CN.md` link to each other.
- READMEs introduce the project; history belongs in `CHANGELOG.md`, installation
  details in `docs/installation.md`, release details in `docs/releases/v0.5.0.md`.
- Original project code uses `GPL-3.0-only`; third-party licenses remain intact.
- Android retains its release certificate, Mac is ad-hoc signed, iOS is unsigned.
- Open a PR against `main`; do not merge without explicit authorization. Tag the
  same verified PR commit for the release.
- Do not claim Windows hardware GPU, physical iOS or native Intel validation.
- Publish only freshly built assets, with corresponding source and checksums.

## Steps

- [x] Fetch `development`/`main`, inspect existing releases, create the worktree.
- [x] Separate and translate project documentation; update licensing and versions.
- [x] Rebuild macOS arm64/x86_64, Windows x64, signed Android and unsigned iOS.
- [x] Verify packaging, versions, signatures, licenses and relevant regressions.
- [x] Record build evidence and stage the five versioned client archives.
- [ ] Package committed project/dependency source, patched LibRaw and checksums.
- [ ] Commit owned changes, push, create/attach the PR and inspect exact-head CI.
- [ ] Tag the verified commit, upload a draft release, verify assets and publish.

The final GitHub operations are evidenced by the PR and release, not by a
post-publication source edit.
