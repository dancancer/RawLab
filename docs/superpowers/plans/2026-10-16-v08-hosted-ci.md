# RawLab 0.8 Hosted CI Implementation Plan

**Goal:** Add real GitHub-hosted verification and an evidence-based 0.8 release checklist without publishing a release.

**Architecture:** Reuse the four platforms' default build entry points, with separate jobs and explicit timeouts. Run CPU-safe render/protocol regressions where supported; keep physical GPU, signing and device acceptance separate. Use read-only workflow permissions, pinned actions, no secrets and no RUM vendor SDK.

**Base:** `development@82b1d8e51e95d5ece5a1a6b6cdc268ea8c92623c`.
**Scope:** CI configuration, small CI adapters/tests, and release-preparation documentation only. Preserve product rendering, versions and the dirty primary checkout.

**Scope amendment (user, 2026-10-16):** macOS must support OS 14. Align app,
dependencies and tests to minimum 14.0, retain Apple Silicon/Intel, add both hosted
architecture builds and keep real macOS 14 runtime acceptance explicitly open.

## Constraints

- PRs target `development`; also verify pushes to `development`, `release/**` and `main` without publishing anything.
- No tag events, release jobs, signing credentials, deployment, `pull_request_target`, private RAW uploads or real RUM traffic.
- Default native builds retain Adobe DNG SDK, Lensfun and denoise; "SDK-free" refers only to the opt-in RUM SDK.
- Cache source downloads only, not cross-source native binaries.
- CI logs record source SHA and toolchain. Upload only allowlisted logs and structured test results.
- The user authorized merging the CI/checklist PR into `development` after independent review and exact-commit hosted CI success. No `main` merge, tag or formal release is authorized.

## Review Focus

- A skipped/missing job must not be mistaken for a required passing gate.
- Default build features must not be disabled merely to make CI green.
- Runner platform/toolchain must support the actual deployment target; target-14 builds on macOS 26 do not prove macOS 14 runtime compatibility.
- Hosted VM/unsigned simulator results do not prove physical GPU, accessibility, signing or installability.
- Historical failed invocations and physical results retain their original source scope.
