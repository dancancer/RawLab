# 已编辑照片与效果缩略图

四端使用同一编辑状态语义，桌面文件浏览器和移动端照片列表显示效果缩略图及单支斜铅笔。iOS 使用独立的“最近打开”入口，系统选图器继续负责导入。

本文为 v1 交互契约。后续改变标记语义、筛选或本机副本保留策略时，应同步更新本契约和 `DESIGN.md`；原生验收记录放在对应 PR。

## 状态与显示

- “已编辑”表示该照片当前保留相对其默认设置的调整。复用各客户端的全量调整判定，包含外观、配方、几何、镜头和适用的 HDR 设置；不能用记录存在、打开次数或未保存 dirty 标志代替。
- 恢复默认或撤销到默认后清除标记；应用预设、粘贴或同步调整后按每张照片重新判定。浏览、缩放、对比和导出不改变编辑状态。
- 照片缩略图右下角使用单支斜铅笔，深色小底、浅色符号。它是不可独立点击的状态标记；普通点击、双击、右键和选片继续沿用已有行为。桌面提示和读屏名称包含“已编辑”。当前照片的强调边框、右上角选片勾选与编辑标记相互独立。
- 缩略图显示当前已提交调整后的实际渲染效果，保持既有网格尺寸与图片比例策略。默认照片可直接使用原始内嵌预览。编辑期间保留上一张完整预览，在一次调整结束且对应结果完成后更新；几何/镜头草稿在应用后才发布。临时查看调整前不覆盖调整后缓存。
- 正在更新时保留已有图并说明预览待更新；没有调整后缓存时可先显示明确标识的原始预览。失败不清除编辑标记，不把旧图描述为新效果。保存失败继续使用已有保存错误与重试入口，不与缩略图失败混淆。

## 缓存与渲染

- 缓存按原照片身份、完整调整快照、外观资源身份、处理版本和缩略图规格区分。原资源或调整变化立即使旧结果不再适用；迟到的异步结果不得覆盖当前请求。
- 优先复用当前照片已完成且匹配的编辑结果。冷缓存只按可见照片低优先级生成，保留原生编辑器和导出的资源优先级，不为展开目录同步显影整批 RAW。
- 复用客户端实际渲染路径，不对相机 JPEG 简单套用 RAW 参数，不新增 C ABI 或改动颜色语义。HDR 缩略图用现有 SDR 兼容呈现。AI 降噪仍遵循硬件 GPU 约束，不静默换成 CPU 推理或跳过已保存的效果。
- 缩略图是有界、可重建的本机缓存，不写入原照片、系统图库、sidecar 或云端。缓存失败不损坏编辑记录。

## 平台入口

- macOS/Windows：当前文件夹树、下方照片区和选片工作区共用编辑状态与效果缩略图，保留当前布局、滚动锚点和选择语义。
- Android：在自有相册增加“全部 / 已编辑 / 未编辑”筛选，保留相册、网格列数、比例和右上角选片控件。筛选仅作用于当前可访问照片；切换筛选不悄悄清除已选项。
- iOS：新增“最近打开”，仅列出本机成功用 RawLab 打开过的照片。保存稳定身份及可重新读取的来源信息，重启后可继续打开；系统 PhotosPicker 和 Files 仍负责导入。增加同样的编辑状态筛选，既有批量编辑列表也显示编辑标记与效果缩略图。
- iOS 最近列表保留最近 100 条记录及约 2 GiB 的私有原片副本；最新单张超过预算时仍保留该张。副本与上次预览存放于本机 Application Support 并排除备份，只有移除或超出保留范围时清理本功能拥有的副本。编辑记录与外部原片不受清理影响。
- iOS 最近记录不因浏览失败被删除，不按同名合并。原图不可访问或内容变化时明确提示，保留可用的上次预览并支持重新选取；未经身份核对不把旧调整套给另一个文件。移除最近记录不删除原照片或其编辑记录。
- 移动端不依赖悬停解释图标；整张照片承担打开/选中操作，读屏提供编辑状态。筛选返回、重置、取消草稿和批量同步后维持合理位置与可理解的数量。

## 验收

需验证：默认/调整/重置/撤销/重做；外观与几何；原文件替换；过期渲染；缓存损坏与冷启动；批量同步后刷新；保存与预览失败分离；当前照片与选片标记并存；移动筛选与选择；iOS 最近记录跨重启重开、权限失效及移除不损坏原图。模型测试验证身份和状态，原生运行验证真实控件与缩略图效果；不能以网页原型或 UI 目标编译替代原生操作验收。
