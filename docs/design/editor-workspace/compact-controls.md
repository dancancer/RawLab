# 紧凑调整栏与裁切精度

本约定补充 [需求](requirements.md) 的 REQ-03、REQ-05 和
[技术设计](technical-design.md)，采用四端一致的交互语义和各平台原生控件。

## 导航与空间

- macOS、Windows 使用两行导航：第一行六组，第二行组内工具。工具图标与名称横排，
  普通字号分别以 36、32 点为预算；长文案横向滚动，不截断名称。
- 当前外观、处理版本和曝光基准放入第一行的“照片处理设置”弹出面板；重置菜单保持可见。
- iOS、Android 保留原生标尺和底部六组导航，工具改为横排图标与名称，命中区域至少
  44 pt / 48 dp。普通字号的横向宽窗使用照片旁的参数栏；大字号沿用纵向重排和底部横滑，
  控件可增加高度并滚动参数，不能缩小文字。iOS 辅助字号的位置与尺寸采用单列，
  短横窗分组保持单行横滑，保证完整标签与数字可以同时进入视口。
- 外层调整栏保持用户或窗口分配的高度。只有参数内容滚动，草稿取消、应用始终可达。
  几何工具直接显示裁切、透视、镜头校正，避免重复显示几何标题和同义工具行。

## 滑块与 HSL

桌面滑块使用直径 14 点的圆形滑块头，轨道、方向渐变、变化区间和默认标记均在其下方。
保留原生键盘、焦点、读屏、重置和温度倒数映射。HSL 八色域可以横向滚动，保留选中、
已调整状态及三轴原值；本次不改变渲染算法或其他参数的合法网格。

## 裁切

直接拖动照片上的裁切框是主要入口。参数区依次提供比例、锁定当前比例、横纵交换，
旋转、翻转、网格及拉直。“位置与尺寸”可展开为 2 × 2 数字控件，不再重复四条长滑块。
桌面就地输入；iOS 使用完整数值的原生滚轮；Android 使用原生数字输入对话框。

位置和尺寸以百分比显示，最多两位小数，新输入步进为 0.01%。仅显示舍入，不对原始
归一化坐标量化；聚焦、打开、关闭或无变化确认不会把舍入后的值写回。无效、越界和
不符合精度的输入保留并提示错误，不静默夹紧。桌面上下键普通步进 0.1%，Shift 为
0.01%，左右键仍移动光标；读屏保留增减、范围、默认值和重置操作。

比例锁以变换后画布的实际宽高为依据，保留完整精度。自由、预设和锁定当前比例只有一个
有效比例来源；宽高数值修改保留左上角锚点并联动另一边，位置修改只移动裁切框。
边界及最小裁切尺寸继续遵循各端已有几何规则。横纵交换取比例倒数，旋转或拉直后按新
画布重新约束。比例锁是编辑状态，不新增照片持久化字段。

收起位置与尺寸时提交有效数字到草稿；无效输入保持展开。开始画布操作前先提交有效
输入，无效输入阻止该次操作，避免被拖拽覆盖。离开工具、取消草稿及关闭窗口继续沿用
已有草稿守卫。应用保持“保存成功后提交”和精确预览完成门控；草稿不能导出。
