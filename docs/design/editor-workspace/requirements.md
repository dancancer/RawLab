## 1. 目标与范围

用户能在照片始终可见的工作区中，快速找到已有调整，切换 HSL 色域并精确调节，辨认和重置改动，并用一致的查看方式核对结果。完成分组后，新增工具可以归入已有组，不再把所有参数平铺。

| 范围              | 本步交付                                                                                                                                                     |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 核心              | 六组常驻导航、组内工具、展开/收起、改动标记、单行参数、精确值、分级重置、HSL 八色域三轴                                                                      |
| r4 编辑工作区配套 | 固定参数区、草稿保护、几何图标和裁切直接操作、对比开关及方式选择、临时查看调整前、细进度条、照片信息、留白开关、移动端纯预览、RGB 直方图、iOS 端点刻度显示   |
| 保持可用并回归    | 原有导入、照片切换、外观/配方应用与管理、单张导出、批量导出与恢复、设置、相机参数不可用提示；沿用现有能力，不借本步重做整套流程                              |
| 不在本步          | 图片取色/目标调整、复制粘贴、命名用户预设、完整撤销/重做、新增黑白场/鲜艳度/颜色分级、多点曲线、清晰度/去朦胧、批量同步与逐张微调、自动下载/安装更新、AI/HDR |

上表“不在本步”仅指不在 ITER-02 子项：MCP、复制粘贴/历史、用户预设、新调色、HSL 目标调整、批量逐张工作流与桌面更新都在本次迭代的其他 ITER 项交付；只有 AI/HDR/视频/Live Photo 在本迭代之外。原型的“规划中”是设计时状态，不是延期决定。相关 ITER 项交付前不提供半套可执行入口，交付后必须替换成真实功能。已有局部撤销、文本编辑撤销不能冒充 ITER-03 的完整编辑历史。

### 1.1 r4 与旧稿的关系

- 一级和二级是信息分组，不是必须返回上一级的页面栈。r4 的常驻分组与展开面板替代 r2 的进入/返回页面。
- 对比保留关闭、并排、分割线三种查看状态，操作改为点按开关、另外选择方式；不再按每次点击三态轮转。
- 手机竖屏及大字号继续单行横滑。普通字号的横屏侧栏按 r4 一次呈现六组：收起时 2×3，展开时六列；这是对旧“所有窗口都横滑”的明确调整。
- `DESIGN.md` 记录已实现的视觉基线；r4 规则的实现与验收进度以[迭代总账](../../integration/editing-iteration/README.md)逐批登记，不能仅因规则已写入本文就当作已交付能力。

## 2. 六组与状态归属（REQ-01）

顺序与稳定 ID 固定如下。名称走现有本地化体系，ID 不用翻译字符串充当。

| ID / 名称               | 本步可用工具                                 | 重置拥有的参数范围                                                            |
| ----------------------- | -------------------------------------------- | ----------------------------------------------------------------------------- |
| `looks` / 外观          | 胶片（含内置和用户导入外观）、大师配方、强度 | 外观引用、配方选择和强度；其他组的有效调整不得被顺带归零，配方耦合按 6.2 处理 |
| `light` / 光线          | 曝光、高光、阴影、对比度、S 曲线             | 用户曝光、适用的曝光基准模式、明暗、对比和现有 S 曲线                         |
| `color` / 颜色          | 白平衡、饱和度、HSL 混色器                   | 白平衡模式与自定义值、饱和度、全部 24 个 HSL 值                               |
| `effects` / 效果        | 暗角、颗粒及各自辅助参数                     | 两个效果的完整参数对象，不只归零主强度                                        |
| `detail` / 细节         | 降噪、锐化                                   | 现有锐化和降噪对象，包含旧记录仍携带的合法降噪设置                            |
| `geometry` / 几何与镜头 | 几何、镜头校正                               | 几何和镜头对象；处于草稿时仅改草稿，应用后才保存                              |

“曲线”在本步仍是已有 S 曲线。`lightness` 的中文统一为“明度”；HSL 索引沿用红、橙、黄、绿、青、蓝、紫、品红（已有代码的“洋红”是同一索引，不新增第九色域）。

分组顺序、入口、标记和重置范围一致；各端不要求采用相同内部模型或数值控件。RAW 专属参数在普通图片上显示不可用原因，不能为了填满分组而创建虚假功能。无照片时隐藏调整区，保留导入入口。

## 3. 导航与空间（REQ-02）

1. 分组栏在编辑时常驻。点击未选分组展开其工具；点击另一组直接切换；再次点击当前组收起参数面板。收起只增加照片可用空间，不清除参数。
2. 本步采用 r4 的进入组默认工具：外观→胶片、光线→曝光、颜色→白平衡、效果→暗角、细节→降噪、几何与镜头→几何。切入 HSL 时保留本会话上次色域；首次使用红色域。导航和色域选择不写入照片调整记录。
3. 展开后，切组、切工具、三轴数值变化、忙状态、保存状态及草稿操作栏显隐都不改变照片区与调整区边界。只有用户显式收起/展开、调整窗口或桌面拖动调整区边缘时允许重新分配空间。
4. 内容超出时仅参数区滚动；分组、组内工具和草稿取消/应用行保持可达。横屏、系统键盘、安全区和大字号不能遮住最后一项；无障碍字号优先纵向重排，允许内部滚动，不缩小文字硬塞。
5. 纯预览和关闭整个调整区之前保留原展开组、工具、滚动位置及查看状态，恢复时返回原状态。切照片完成保存/草稿处理后恢复该照片的调整，导航本身不使新照片被标记为已编辑。

### 3.1 平台布局

| 平台 / 窗口                  | 规则                                                                                                                                                               |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 手机竖屏、窄窗口、大字号     | 底部单行横滑分组，参数在其上方；边缘提示还有内容。组内工具采用图标与名称横排，iOS / Android 的点击区域至少为 44 pt / 48 dp；大字号保留自然宽度                     |
| iOS/iPadOS、Android 横向宽窗 | 可用宽度至少 600 逻辑单位、宽大于高、非无障碍大字号时采用照片旁侧栏；侧栏约 320 逻辑单位。六组全部可见：收起 2×3，展开六列紧凑行；文字与触点不足时回退底部横滑布局 |
| macOS                        | 左文件树与照片/底部调整区关系不变；六组位于调整区顶部，保留收起、恢复及用户调整高度的能力；至少覆盖 950×620 窗口                                                   |
| Windows                      | 保留 WPF 菜单、文件区与底部调整，六组在调整区顶部；至少覆盖 1024×720，沿用 Segoe UI/微软雅黑、原生焦点与键盘语义，滑块头统一为 14 DIP 圆形                                               |

普通字号参数区采用统一高度预算，具体像素由原生布局按可用空间计算，不把原型 CSS 高度复制成设备常量。三条 HSL 轴在标准手机竖屏可同时操作；无障碍字号允许滚动。

## 4. 参数行与精确输入（REQ-03）

- 普通字号为“名称—滑杆/刻度尺—数值—单位”一行。数值框只包含数字，符号属于数值；EV、K、%、° 在框外次要显示，没单位也保留对齐位置。不把 HSL 值当作角度或百分比重新换算。
- 不常驻显示默认值、范围和每行重置按钮；这些信息仍需通过精确输入、帮助和无障碍描述取得。难理解的辅助项可加简短解释。
- 大字号改为名称和数值一行、滑杆另起一行。开关使用原生开关；两三个简短互斥选项用分段控件，较多选项用菜单。照片多选等仍用复选框。
- 未修改的数值为中性色，已修改值与选中工具用黄色，并同时提供非颜色标记。重置、自动等次要操作使用中性色。
- 滑杆从该参数的有效默认值填充到当前值，而不是一律从最左填满；默认值不等于 0 时也成立。两侧都可调整的参数分别显示方向，输入和显示不能改变原渲染参数的正负含义。
- iOS 保留原生完整数值单列选择、当前值、取消/应用和默认动作；Android 使用数值对话框；桌面支持数字输入、Enter 提交和 Escape 取消。非法/非有限/越界输入不能提交，错误说明留在输入界面，不静默保存成另一数值。
- 输入弹窗只有本地草稿；取消、返回和无变更应用/关闭均不提交。应用合法值才产生编辑。既有记录中不在当前步进网格上的合法值可查看并原样保留，例如移动端 HSL 的 0.5 不能显示成 1：编辑界面的读数、输入初值、辅助提示、摘要和拍摄数值最多显示两位小数，iOS 值轮仍保留完整原值候选；显示舍入不改变保存值、撤销记录或渲染参数。打开后直接应用或确认未变的显示文本仍保留原值；用户正在编辑的草稿可输入完整精度，提交后重新按两位格式显示。细调步进若小于百分之一，用分数（如 `1/1000`）准确表示。实际拖动/选择新值后才采用本端步进；手工输入的新非网格值需说明合法步进，不静默舍入。
- 移动端每个参数面板只有一个“精细”开关，拖动灵敏度为普通模式的四分之一；不改变合法范围、离散步进、数值输入或保存精度。本步将其作为面板会话状态，切工具/组后恢复关闭，不写入照片。

### 4.1 iOS 刻度尺（REQ-04）

延续移动刻度、合法值网格、方向判断和 Reduce Motion 规则。可见刻度始终覆盖控件宽度；当前值在中部时指示线居中，接近最小/最大值时刻度窗口停在边界，指示线移向相应边缘。不得出现半条空白刻度、跳值或只能依靠拖动指示线才能调整的暗示。

色温继续使用既有倒数色温映射，不能按普通线性参数替换。视觉窗口改变不改变当前值、温度方向、精细灵敏度、触觉触发规则、值轮或原生参数范围。

## 5. HSL 混色器（REQ-05）

| 项目     | 行为                                                                                                                            |
| -------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 色域     | 固定八色顺序，一行排列；窄屏/大字号必要时横滑，不能自动折成两行。选中只有外圈，无中心点；改动标记在色块下方，与选中外圈分别表达 |
| 参数     | 色相、饱和度、明度三轴同时呈现，不再为三轴增加页面层级；色域切换保留各自三值                                                    |
| 值       | 三轴均 `[-100,100]`，默认 0；复用既有整数或小数输入精度及保存格式，不更改核心语义。色相 100 不是 100°                           |
| 方向提示 | 色相轨道示意邻色方向，饱和度灰→彩色，明度暗→亮；仅为输入提示，不宣称完整色彩预测或精确取色                                      |
| 精确调整 | 使用 REQ-03 的原生数值入口；读屏表达色域、轴、完整值、选中及已调整状态                                                          |
| 渲染     | 继续走现有 HSL、强度、配方和保存链路；相同照片与最终参数应得到与改版前一致的结果                                                |

修改任一色域/轴后，只有目标字段变化。色域/面板切换不触发新的图像处理、落盘或舍入。全部 24 值为默认时，色域、HSL 工具、颜色组的 HSL 贡献标记消失；颜色组可能因 WB/饱和度仍有改动标记。

## 6. 改动标记与重置（REQ-06）

### 6.1 有效默认值

是否已调整由当前存储的逻辑参数与该照片的有效默认值比较，不依赖操作历史，不比较原型 fixture，也不只比较乘强度后的渲染结果。包括无外观/无配方、强度 100、RAW 默认曝光基准和拍摄时 WB、普通图片的 sensor/none 模式，以及暗角/颗粒/降噪的完整默认对象。辅助参数在主强度为零时仍按真实存储值判断改动，不能把“暂不生效”当作“未修改”。

配方写入的曝光、HSL、tint 等也计入各自组/工具的改动标记，不仅标记外观组；强度为 0 也不隐藏这些待用值。没有“只清用户额外调整”的隐含分层：重置光线/颜色会清除该组存储的配方贡献及手动值，但不重放配方，也不影响其他组。当前色域标记同样按存储的三轴判断；白平衡使用配方感知的默认解析，不能拿相对 tint 0 与相机绝对 tint 直接比较。

新照片默认中性、无胶片/配方；原型的 PROVIA、5600 K、绿色域数值仅为布局示例。旧记录缺少字段时沿用已有兼容分支，例如缺失曝光模式保留历史 scene 语义，不因新的默认改为 preview。

### 6.2 重置入口与确认

| 范围         | 入口和确认                                                                          | 影响                                                          |
| ------------ | ----------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| 单值         | 双击参数名称或滑杆/刻度尺；无障碍“恢复此值默认”动作；不需要确认                     | 仅一个值；WB 模式联动沿用既有合法转换，不能恢复成伪造相机校准 |
| 当前工具     | 右上重置菜单；无变化时禁用；普通工具不需要确认，配方独立化涉及模式/数值转换时需确认 | 工具拥有的完整参数；保留其他工具                              |
| HSL 当前色域 | HSL 重置菜单第一项，带色名；无变化时禁用；不需要确认                                | 当前色域三轴归 0，其他七色域、WB、饱和度不变                  |
| 全部 HSL     | HSL 菜单；确认列出八色域三轴                                                        | 24 值归 0，其他工具不变                                       |
| 本组         | 菜单显示组名并确认                                                                  | 仅 REQ-01 定义的字段范围                                      |
| 全部调整     | 菜单最后一项，确认说明当前照片与完整范围                                            | 当前照片恢复有效默认；不改其他照片、导出任务或原文件          |

HSL 菜单顺序为“当前颜色 → 全部 HSL → 颜色组 → 全部调整”，其他工具为“当前工具 → 本组 → 全部调整”。重置动作、确认和取消之后返回原工具/色域；全组重置不能暗中跳到 HSL 或曝光。

分组重置是一次范围明确的编辑，只提交一次保存和预览请求。选择/应用配方、改变其整体强度继续使用原行为，不在本步拆分配方强度算法。其他组重置不能重新应用配方覆盖已保留的组。

**配方耦合的方案选择：** 当前配方身份和强度参与曝光、明暗、WB、HSL 的解释，“重置外观组”不能简单删除 ID。先将其他组的有效参数无损转换为独立调整，再清除外观身份并恢复强度；需要把配方相对 tint 变成自定义 WB 或改变显示数值时，在确认中说明涉及项目。重置当前大师配方也走这条独立化规则，不能从工具级重置绕过确认。若现有格式不能精确表示（例如物化后的曝光超过现有范围，或缺少所需相机 WB 校准），本次不执行重置，提供取消或另行确认“全部重置”；不静默夹紧、丢弃或自动扩展参数格式。这是本方案为满足“组重置不串组”作出的取舍，须与技术方案一起评审。

完整撤销/重做由第 2 步交付，本步的确认文案不承诺已有全局撤销。

## 7. 几何、镜头与草稿（REQ-07）

- 旋转和翻转继续使用原语义图标，四端方向一致，保留可访问名称。裁切以照片上的四角/四边手柄为主，框外压暗，可显示三分网格；精确裁切放在展开区。
- 拖动、比例、旋转、翻转、拉直、透视和数值输入都操作现有几何草稿；镜头参数操作现有镜头草稿。不改几何顺序、坐标、最小合法区域或镜头解析规则，不把原型 10% 裁切最小值当作契约。
- 草稿取消/应用行固定在参数区内部。未改动、手势进行中、当前精确预览尚未完成、尺寸收敛中时应用禁用；任何几何/镜头草稿存在时保持导出入口禁用。
- 离开工具/组、收起面板、隐藏调整区、导入或切照片均先处理草稿。有修改时提供“应用并离开 / 放弃修改 / 继续编辑”；无修改可直接退出。继续编辑不改变原导航或值；放弃不保存草稿。应用成功必须包含候选编辑记录已持久化成功，之后才替换提交状态并执行待办导航；保存期间禁止重复应用，失败保留草稿与原提交状态、留在当前照片并允许重试/放弃，不把内存赋值视为保存成功。离开照片前原已提交但未保存的编辑也必须保存成功。
- 原地应用或取消后回到光线→曝光，沿用当前平台约定；“应用并离开”则继续用户原先请求的目标组/导入等。应用不可用时不能从退出弹窗绕过精确预览门控。
- 草稿期间不启用纯预览或按住查看调整前，手柄拖动不触发画布点按。重置当前几何/镜头工具直接作用于对应草稿；重置整个几何与镜头组确认后把两者默认值放入同一待应用草稿，应用前两者都不落盘。触发“全部重置”则先处理草稿：应用成功或放弃后，基于得到的提交状态重新准备全量重置并单独确认；继续编辑即取消重置。若最后取消全量重置，前面明确确认的应用/放弃仍生效；无修改草稿可退出后直接进入全量重置确认。

## 8. 查看与对比（REQ-08）

### 8.1 开关与方式

四端采用对称矩形外框加中线图标。点按关闭/打开；打开恢复本会话上次方式，首次默认并排。桌面下拉菜单、移动端长按图标或画面内的方式切换提供并排/分割线选择，另有可访问的关闭入口。关闭后不得被迫经过另一方式；切图记住偏好方式，但清除临时按住状态、重新建立该照片参考。

- 并排共享照片坐标、裁切、缩放和平移，长宽比例适合时左右排列，画布高窄时上下排列。布局只占用既有照片区域，不挤高调整区。
- 分割线在实际照片矩形内移动，默认中点；不延伸到黑边、工具区或标签。支持拖动、键盘方向键、Home 回到中点及读屏调整，不改变任何照片参数。
- 两种方式均明确标识“调整前/调整后”。调整前沿用当前客户端的中性参考定义，几何/镜头使用与结果一致的构图；不把嵌入 JPEG、上一次低质量代理或另一个照片的参考混作调整前。具体基线见技术方案。
- 开关、方式、分割位置和临时查看均属查看状态，不触发调整自动保存，不参与复制、配方、导出参数。

### 8.2 手势与纯预览（REQ-09）

没有常驻对比和草稿时，按住照片临时看调整前，松开恢复；桌面反斜杠键按下/抬起提供相同行为，输入文本时不生效。移动、缩放、多指、取消、失焦、后台或切图必须结束临时状态，不能卡在调整前。

移动端单击照片进入纯预览，再单击恢复。手势判定顺序是裁切/控件操作、缩放与平移、按住、单击；长按完成不能再派发单击。纯预览保留编辑与原导航，关闭常规叠层；提供读屏退出动作，系统返回优先退出纯预览，不直接离开照片。双击缩放若平台原来支持，须与延迟单击识别协调，不能先闪入纯预览。

## 9. 照片信息、留白、直方图与处理状态（REQ-10）

- 信息入口位于照片左上角，依次为隐藏、文件信息、拍摄参数；工具栏/更多入口指向同一状态。桌面 `I` 在非文本输入时可用。白平衡等细节进入信息层，文本不拦截画布缩放和平移。
- “缩放与显示”提供“照片四周留白”，默认开启；Windows 在查看菜单提供相同选项。关闭只减少查看边距，仍完整容纳照片，不等于填满裁切、修改宽高比或保存几何参数。
- 四端使用 256 bin RGB 输出直方图，R/G/B 分开、重叠按加色显示；与 macOS 的输出 sRGB 语义一致。普通显示及并排/分割线统计调整后；临时查看调整前则切到中性参考统计并标识，无相应真实数据时不绘制旧数据或示例山形。折叠状态保留。iOS 的亮度直方图需要接入真实 RGB 数据，不只换成三种颜色。
- 预览处理使用照片顶部叠加的约 2 逻辑单位细线；没有真实百分比时用不定进度，不编造完成率。不改变布局、不抢焦点；读屏能获知忙/完成/失败，避免每次拖动高频播报。
- 忙状态绑定最新预览请求及尺寸收敛，旧请求结束不得错误隐藏新请求进度。处理期间保留最后有效图；失败给出重试且不冒充最新预览。新图可先于统计显示，交互预览允许跳过统计，但此时清空/暂隐直方图绘图并保留叠层布局；只有同一已接受帧的统计完成后才恢复，不继续显示另一帧的旧统计。保存失败另显示“调整未保存”，预览完成不等于保存成功。
- 只改导航/色域/标记不触发解码。实际参数调整继续使用现有交互代理与停止后的精确预览；移动端“100%”不因此升级为全尺寸 RAW 细节证明。

## 10. 可访问性、本地化与兼容（REQ-11）

- 沿用中文、英文、德文、法文、日文、西班牙文；全部新增标签、动态色域/组名、确认、错误、单位和无障碍状态走资源契约。胶片和大师配方专有名称保留。
- iOS 点击区域至少 44×44 pt，Android 至少 48×48 dp；可见色块/图标可以更小。八色域不足宽度时滚动触点，不把点击区域压成 30 dp。
- 选中、改动、忙和不可用均不能仅依靠颜色。菜单可键盘进入/退出；弹窗初始焦点在内容/标题而非破坏性动作，关闭后返回触发点。组收起、旋转和切工具后焦点仍有效。
- 屏幕阅读器有明确的组、工具、色域、轴、值和重置范围。双击重置另提供语义动作/菜单入口，不与 VoiceOver/TalkBack 的激活手势冲突。Reduce Motion 下不播放游走进度或刻度动画，保留静态状态说明。
- 不改变原有照片身份、持久化格式、渲染顺序、C ABI、Agent v4 与批量快照语义；原始照片只读。保存后重新打开的值、预览与导出保持一致。
