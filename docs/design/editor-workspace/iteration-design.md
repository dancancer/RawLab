# 本轮新增界面与交互

[四端设计板](index.html) · [覆盖表](coverage.html) · [迭代总需求](../editing-iteration/requirements.md) · [总技术方案](../editing-iteration/technical-design.md)

本文件维护 ITER-03～11 的界面分工、状态和操作约定。它与 ITER-02 的[工作区子需求](requirements.md)共同使用；参数合同、算法和真实保存规则仍以迭代总需求和技术方案为准。设计版本、批准状态、实现状态只读取 [manifest.js](manifest.js)。

本轮补稿继续使用原有 HTML 资产、令牌、图标与照片示例。四端共享场景语义和稳定 ID，保留 iOS 值轮、Android 数值对话框、macOS/Windows 键盘输入及各自窗口外观。移动端一级分组保持单行横滑，Android 沿用已评审密度；照片与调整区外层高度保持，复杂工具在参数区内滚动。

## 调整复用与历史

范围选择复用同一组件，支持“全部 / 仅已修改 / 自定义”、组展开和 HSL 色域/轴展开。几何与镜头默认排除，全部或显式选择才包含。复制冻结当时的内容；来源之后的修改不改变剪贴内容。预设有独立身份和内容，不借用剪贴板作为存储。

预检显示来源、目标身份/位置、数量与范围。集合里故意保留两张同名但不同位置的照片，防止以文件名识别目标；来源不可选为覆盖目标。目标不兼容时按照片列出受影响项，取消或明确跳过，跳过范围不得扩大到兼容目标。结果按逐张成功、失败与跳过呈现。

来源脏草稿先应用并保存、放弃或继续编辑；目标草稿逐张应用、放弃、跳过或取消。草稿应用是独立编辑，之后取消粘贴不撤回该确认。保存失败保留草稿并提供重试。设计稿的错误入口用于审阅失败分支，正常点击不随机注入错误。

会话历史区分当前照片与本次批量事务；显示实际成功目标，失败目标不参与撤销。后续单张修改与整批撤销冲突时默认取消，可明确只撤销无冲突子集。已经撤销的目标不重复处理，逆向保存失败单独重试。输入框保持系统文本撤销优先。桌面复制范围/粘贴为 Cmd/Ctrl+Shift+C/V，会话撤销/重做为 Cmd/Ctrl+Z、Cmd/Ctrl+Shift+Z。

## 新工具的输入与状态

新标量建议使用 -100～100、0 为中性；颜色分级使用三明暗区各自色相和饱和度，没有第四个轮。色相在饱和度为 0 时仍可保留。色轮支持拖动和方向键，精确数值继续使用原平台控件；重置当前分区不影响另外两区。

多点曲线首批只有全局 RGB 主曲线。固定两端，2～33 点；x 严格递增、y 非递减，移动受相邻点约束，方向键调整选中点，Delete/Backspace 只删除中间点。S 曲线切到多点会明确确认从直线开始，不宣称无损转换；返回 S 曲线也先确认丢弃当前多点编辑。曲线图只表达控制点输入，实际插值与处理必须按技术方案实现。

HSL 目标模式优先处理照片手势，期间不触发按住对比或移动端纯预览。一次拖动从冻结起点计算，不把预览增量反复累加。原型的像素、放大镜与相邻色域权重明确标注“取色示例”，不代表真实取样。过期帧先更新再取样。

每个新工具独立提供非法输入、预览失败、保存失败与恢复深链。失败保留当前工具、分区/控制点、合法参数和最后有效照片；只有恢复成功后才移除未保存提示。控件和错误动作的移动端触点沿用 iOS 44、Android 48 的平台令牌。

## 批量与桌面恢复

同步会保存每张目标的调整；“仅用于本次批量导出”保留旧的统一快照流程，文案和入口分开。单张微调后返回原集合，保留顺序、选择和其他目标的值。草稿或保存失败先处理，再返回或冻结导出。

逐张导出确认列出每张最终调整，启动时冻结身份、顺序、参数、外观和输出设置。取消、中断、权限恢复和失败重试沿用这些快照，不读取之后的照片修改，不重复成功项。移动端不确定保存结果先核对再恢复；明确放弃未处理项后保留已成功输出，结果写为“未处理项已放弃”，不能称全部导出成功。

桌面更新只对受支持的安装形态开放自动安装设置；旧 ZIP/portable 先手动迁移，不显示可用的自动安装开关。macOS 单独提供 arm64/Intel 入口，Windows 使用 x64 当前用户 Setup。安装门槛同时列出脏草稿、保存失败和仍运行的任务；等待时不强制结束导出。

安装/重启失败保留可启动版本与用户数据，恢复旧版时使用对应备份并保留新格式副本。新版已有编辑后不提供自动降级，进入明确备份和手动恢复说明。上述均为设计状态，原型不下载、校验、替换应用或写磁盘。

## 维护与验证边界

`shared/iteration-model.js` 登记 ITER、场景 ID、平台和状态类别；`shared/screens.js` 合并为唯一评审目录，覆盖表与设计板读取它。`iteration-tools.js` 维护调色控件；`iteration.js` 维护复用、预设、集合与更新流程；`iteration.css` 承接其布局。新条目先登记，再补可操作页面，评审发现缺口继续登记在覆盖表。

浏览器检查分别记录场景/尺寸组合、既有交互回归和本轮关键路径；截图是临时评审材料，不替代源资产。真实像素处理、照片质量、持久化/重启、系统权限、物理设备手势、原生读屏和实际更新安装仍须在原生开发后验收，设计稿通过不能计为这些交付通过。
