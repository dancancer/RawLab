# Sony 相机导入：UI 与交互设计

设计版本：r1，2026-11-08。状态：待确认的产品设计，独立于已完成的协议实验。

[打开交互原型](prototype/index.html) · [协议与存储设计](sony-wifi-design.md) · [当前实验工具](../../../tools/camera-transfer/README.md)

## 1. 用户任务与设计决定

用户已经确认主场景：**在 RawLab 里挑选几张照片，再导入编辑**。首版围绕已跑通的
α7C II、macOS 和 PC 遥控连接展开，其他机型按后续兼容清单开放。

采用独立、非模态的「相机导入」窗口。相机照片、选片和传输在这里完成，用户明确点击结果动作后，
才把本地照片交给已有编辑器。这个窗口可以关闭并重新打开，传输任务由应用持有。

考虑过三种入口结构：

| 结构 | 取舍 |
| --- | --- |
| 小型工具栏弹层 | 适合显示连接状态，空间不足以挑图和比较，不作为主界面 |
| 在编辑器文件树中加入远程相机 | 能复用浏览布局，但会混淆「相机上」与「本机已保存」，还会牵连当前编辑导航 |
| 独立导入窗口（本设计） | 保留足够的选图面积，可与编辑器并行；明确在保存完成后交接本地文件 |

沿用 [DESIGN.md](../../../DESIGN.md) 的 Operate 模式：深灰连续表面、系统字体、原生控件、
黄色选中轮廓与主要操作。照片占据最大面积；不引入新的品牌视觉或全局工作区模式。

## 2. 入口与窗口

- 文件菜单在「打开照片…」之后增加 **「从相机导入…」**。不复用已有的「导入相机配置…」，后者是外观配置。
- 「打开照片」保持现有单击行为；其相邻下拉菜单补充同一入口。空画布提供次要文字按钮「从相机导入」。
- 一次只打开一个相机导入窗口，再次触发入口时置前并恢复原状态。
- 建议初始内容尺寸 `1120 × 740 pt`，最小 `840 × 600 pt`。大窗口左栏 `200 pt`，照片区自适应。
- 低于 `1000 pt` 隐藏日期侧栏，改为顶部日期菜单，照片网格从四列变三列；不缩小文字与点击目标。
- 关闭窗口不等于停止任务。传输仍在进行时，在主编辑器工具栏显示「正在导入 2/4」；点击可恢复窗口。
- 退出整个应用且任务尚未完成时，使用系统确认：**「停止导入并退出」/「继续导入」**。完整照片保留。

## 3. 首次连接与再次连接

首次打开呈现简短准备说明和相机地址，不要求先选品牌或研究协议。

1. 提示「将相机和 Mac 连接到同一 Wi-Fi，并在相机开启 PC 遥控」。展开「相机上怎么设置」才显示菜单路径。
2. 输入相机 IP，点击「查找相机」。首版不伪造自动发现；最近使用过的地址可一键选取。
3. 接收到相机身份后，显示访问认证表单：用户名、隐藏密码、相机指纹。指纹完整换行展示，可复制。
4. 用户核对相机屏幕上的指纹，勾选「与相机上显示的指纹一致」，再点击「连接相机」。认证前完成指纹确认。
5. 「记住密码，保存在钥匙串」默认关闭。若用户选择，密码进入系统 Keychain；否则仅留在本次会话内存中。
6. 连接完成后进入照片网格。只展示相机名称和连接状态；型号、固件、地址放在「相机详情」。

再次使用：上次相机以一行显示名称及「连接」，记住过凭据时直接连接，否则仅补密码。
相机地址变化可编辑，不新增另一个重复设备。连接失败时保留已填写的非密码信息。
指纹变化时停止认证并重新核对，不自动接受，也不提示关闭访问认证。

连接过程中显示「正在连接 α7C II…」，允许取消；没有确定阶段的百分比不显示进度数字。
相机被官方 App 占用时提示「相机正在被其他应用使用」，恢复动作是「重试」，补充关闭其他连接的说明。
未支持的型号/固件提示具体原因，并给「从文件打开」；不在普通 UI 暴露 experimental、profile 或任意端口。

  α7C II      12 张照片                 最新在前     刷新

  全部日期    文件名  格式 · 大小；已导入状态另行标注

  导入记录
──────────────────────────────────────────────────────────────────
已选 3 张 · 137.6 MB        查看已选 / 清空选择      [导入 3 张]

### 缩略图与筛选

- 默认按拍摄时间倒序，按日期分组。默认显示 RAW，格式菜单可切到全部、JPEG、HEIF，记住上次选择。
- 网格使用等高照片框，缩略图完整适配框内，不裁掉竖幅构图。每项只常驻文件名、格式和大小。
- 原始文件大小未知时显示「大小未知」，选中总大小显示「约 X MB，另 N 张大小未知」，不伪造精确值。
- 首版每个实际文件独立显示与选择。RAW+JPEG/HEIF 不按文件名猜测合并，避免误将两份文件算一张。
- 日期、格式和文件名搜索可组合。筛选改变不清空选片；底栏明确提示「其中 N 张不在当前筛选中」。
- 「查看已选」切到已选项集合，再次点击回到原筛选。刷新保留可重新匹配的选片，移除或变化的项单列提示。
- 相机缩略图按可见区域加载。加载中显示稳定占位；失败显示文件名和「预览不可用」，仍可选择、导入原文件。
- 清单尚未完整时显示「已找到 N 张，仍在读取…」；不能把当前已读数量宣称为存储卡总数。

### 选择与预览

- 单击照片切换勾选；Shift 单击选择当前排序中的连续区间。与已有 RawLab 选片规则一致。
- 双击或空格打开大图预览，不启动下载，也不改变双击之前的勾选结果。
- 预览中左右方向键切换，空间按可获得的预览分辨率展示；底栏明确标注「相机预览」。
- 预览中的「选中照片 / 取消选中」立即同步网格；Escape 关闭预览并回到原焦点。
- `⌘A` 选择当前筛选结果，`⌘D` 清空选择；方向键移动网格焦点，Return 切换勾选。
- 没有选片时「导入」禁用；相机已断开时保留勾选，按钮改为「重新连接」。

## 5. 导入与结果

点击「导入 N 张」即开始，不再弹出重复确认。默认保存到 RawLab 管理的相机原件目录；
底栏的保存位置说明可展开查看并在 Finder 中显示，不要求用户每次选目录。
开始前检查可用空间，空间不足直接在底栏说明差额并提供更改保存位置的入口。

任务开始时冻结本次选择，传输逐张进行。仍可浏览和放大预览；完成后点击「继续选片」开始下一批。
首版同一相机只运行一批，不在传输中混入新的选择或第二批任务。

- 底栏显示实际完成张数、当前文件、已收字节/总字节和线性进度；不展示没有依据的剩余秒数。
- 「查看任务」展开逐张状态：等待、正在导入、已保存、失败。进度只统计传输，不包含编辑器解码。
- 「停止导入」立即停止当前数据流和未开始项；已保存项保留。本操作可重新开始，无需再确认。
- 原件完整发布后才计入「已导入」。落盘、空间不足、格式错误和网络失败都不能提前显示成功。
- 关闭窗口继续传输；在主编辑器只留小型任务入口，不覆盖正在编辑的画面。

完成时在原底栏就地显示结果，不弹居中成功窗口：

| 结果 | 文案与主操作 |
| --- | --- |
| 1 张成功 | 「照片已导入」→「打开编辑」 |
| 多张成功 | 「已导入 N 张照片」→「加入选片集合」；交给现有集合窗口继续挑选/单张微调 |
| 部分失败 | 「已导入 3 张，1 张未完成」→「重试未完成」；同时可「编辑已导入照片」 |
| 用户停止 | 「已停止，2 张照片已保留」→「继续未完成」或「查看已导入」 |
| 已有相同内容 | 「已在本机」；复用原路径与调整记忆，不额外生成副本 |
| 已保存但不可编辑 | 「原文件已保存，当前无法编辑」→「在 Finder 中显示」；不把保存成功改成传输失败 |

「已导入」标记需要持久源记录且本地文件仍可用。跨会话的同名、同大小本身不足以跳过下载；
身份不足时，下载后依据内容去重。产品文案不向用户暴露摘要算法或 source ID。

## 6. 断线与恢复

断线后在照片区顶部显示固定提示：**「与相机的连接已断开。已导入的照片保留在本机。」**
保留当前日期、搜索、滚动位置和已选项；当前部分文件丢弃，已完成项不重下。

「重新连接并继续」重新核对设备和当前文件清单后，从未完成文件的开头重新下载。
不将这个动作称为「断点续传」。若照片已删除或换卡后无法匹配，提示具体项并提供「跳过」。
不连续弹系统警报，也不在后台循环索取密码。

应用异常退出后恢复任务元数据，下次显示「上次导入未完成」及「继续未完成 / 仅查看已导入」。
连接失败、认证失败、找不到相机和休眠使用同一位置的状态反馈，恢复动作按原因给出。

## 7. 与当前编辑器交接

网络下载与编辑器 `model.importing` 分开，不能因为后台传图把曝光、裁切或导出全部禁用。
点击结果中的编辑动作才调用现有打开/集合入口，并复用保存、导出及几何/镜头草稿门禁。

- 有未应用草稿：复用「继续编辑 / 放弃修改 / 应用并离开」。选择继续编辑仅取消这次切图，原件照常保留。
- 编辑器正在导出/打开其他照片：显示「照片已保存，当前操作结束后可打开」，按钮保持可恢复，不抢占画布。
- 导入记录可以离线打开、加入集合、在 Finder 显示，不要求相机仍在线。
- 离开导入窗口不自动把当前编辑参数应用给新照片；每个持久原件继续遵守既有调整记忆规则。

## 8. 视觉、可访问性与边界

照片网格沿用 4 pt 圆角、6 pt 选中轮廓范围和黄色功能色。普通正文 13 pt、辅助信息至少 11 pt，
主要标题 18–20 pt，数字使用等宽数字。单项选择同时具有勾选符号、轮廓和可访问状态，不能只靠变黄。

原生实现使用 SF Symbols、`SecureField`、系统菜单、系统 `ProgressView` 和 Keychain。
焦点环清晰可见，选择数量与失败变化通过合适的可访问状态播报；字节进度不逐包打断读屏。
动效只用于 150–200 ms 的面板展开与状态衔接，尊重 Reduce Motion。

手机后续使用全屏「从相机导入」页面：日期改顶部筛选、两至三列网格、底部固定选择条；
返回上一页保留选择，传输页有独立结果。不把 Mac 的三栏缩成手机，也不在此稿宣称移动端已实现。

原型仅模拟连接、挑选、预览、进度、断线、重试及编辑交接，示例照片和元数据均为设计素材。
它不会连接真实相机、读取用户文件、保存密码或改变 RawLab 数据。原生实现仍需补齐：
缩略图读取、队列协调、Keychain、导入记录 UI 和打开结果回执；当前 CLI 不能直接视为这些界面已经具备。
