# 移动端相机工作区

日期：2026-11-10。版本 `camera-ui-r3`。状态：**已批准实施，双端原生验证中**。

[统一可点击设计稿](../editor-workspace/mobile-review.html) · [移动编辑工作区](../editor-workspace/mobile-workspaces.md) · [既有移动端方案](mobile-ui-interaction.md)

目标是相机入口、选择、导入和联机拍摄的导航及空间分配。用户已授权 iOS 与 Android 按本稿实施，双端均有原生入口；协议单元测试、原生 UI 和相机硬件验收分别记录，不能互相替代。[无线联机拍摄](wireless-tethering.md) 记录已有机型与固件证据；该清单不作为新版设计的连接准入规则。

## 交互

- 编辑器的「相机」进入独立入口，始终可选「导入照片」与「联机拍摄」。页面路由与协议模式分离，不按上次的 CameraMode 自动进入旧工作区。
- 两种任务共用相机选择与连接页。候选、重新搜索、权限恢复及通用「手动连接相机 Wi-Fi」可直接找到。发现结果包含未验证机型，不因未收录型号或固件而隐藏、禁用或拒绝连接。
- 「如何连接」是连接页标题旁的独立入口；点击进入二级页面，详细文字不常驻连接页、不以内联展开或弹窗替代。返回保留任务、相机候选与选择，不自动重扫或重连。
- 返回逐级关闭预览和子页，再回相机入口，最后回编辑器；重新进入仍显示入口。进行中的导入任务使用独立的任务快捷入口；暂停联机会话作为明确的恢复选项，不劫持主入口。
- 工作区更多菜单包含更换相机、保存位置、导入记录和断开连接。切换相机前等待旧会话完全释放，旧代次结果不能回写新会话。
- 断线时显示明确状态并停用拍摄和参数写入；最后画面加遮罩和标签，不能伪装实时取景。已保存原件和当前队列仍可查看。重连不自动补拍。

## 如何连接：二级说明页

`camera-ui-r3` 按用户明确要求增加此页。路径为「选择与连接 → 如何连接」，顶栏返回和系统返回均回到原连接页。说明页独立滚动；单独打开说明不会发送配对、网络或相机命令。

内容包括：连接前准备；支持蓝牙配对时的发现与确认；显示 SSID／密码时的手动 Wi-Fi 连接；联机拍摄的原件保存设置；搜索不到、蓝牙已配对但 Wi-Fi 未连接、无互联网网络及部分功能不可用的处理。菜单名称以实际机身为准，示例不变成机型选择门槛。

- α7C II 的机身入口按 Sony [智能手机连接说明](https://helpguide.sony.net/ilc/2360/v1/en/contents/202h_register_smartphone.html) 核对；该页同时说明不经蓝牙配对的 SSID／密码路径。
- 初代 ZV-E10 的开关、连接和密码画面按 Sony [SSID／密码连接说明](https://helpguide.sony.net/ilc/2070/v1/en/contents/TP1000201574.html) 核对，不把蓝牙配对写成它的必经步骤。
- 保存设置分别参考 [α7C II](https://helpguide.sony.net/ilc/2360/v1/en/contents/201h_remote_shoot_setting.html) 与 [ZV-E10](https://helpguide.sony.net/ilc/2070/v1/en/contents/TP1000201572.html)；不把两者的具体选项名称互相套用。

这些官方资料用于核对机身侧菜单。RawLab 的发现、返回与能力反馈是本产品设计，不把官方 App 的步骤或支持承诺直接归为 RawLab 已实现能力。

## 兼容性：实测记录与连接资格分开

用户已明确要求「不把已验证机型作为准入限制」。新版设计允许其他 Sony 型号与固件被发现、选择、手动连接和尝试握手，不要求用户从已验证列表选择型号，也不因缺少实测记录拦截。

连接后按认证结果、实际协议与能力分别开放浏览、原件下载、取景、快门和参数控制。没有相应协议适配或某项功能不可用时，说明具体原因，并保留已可用的其他功能；不再统一归因为「型号未验证」。已验证清单只记录已做过的实测，不等于所有其他相机不兼容，也不表示未验证相机全部兼容。

该决策取消型号／固件白名单准入，保留协议与命令语义的校验：未知命令不因设备广告就自动执行，认证不静默降级。Android 和 iOS 的发现与握手按广播服务、协议操作码、属性及描述符核实能力；型号只用于显示与实测记录，不参与连接准入或协议选择。手动 Wi-Fi 按实际网络身份隔离任务，不按 SSID 型号后缀过滤。

## 导入照片

沿用 RawLab 灰色背景和黄色功能强调。顶部只保留返回、相机身份与更多；次行只有当前范围、数量、筛选与全选，保存路径和历史不常驻。

照片网格占主要空间。正常字号使用三列紧凑缩略图，大字改为两列；不依靠缩小触点和文字增加密度。照片项只保留图像、选择框、短文件名及 RAW/JPEG／已保存状态。点击选择；选中一张时底栏显示预览入口，长按作为补充操作。不要在每张图片下重复一枚大预览按钮。

未选择时没有固定操作底栏。选择后显示一行数量、总量与导入按钮；传输任务另有明确的进度、失败和恢复状态。筛选在独立面板中进行，日期列表可滚动且应用动作固定可达；已选择但被筛选隐藏的照片仍计入总选择，提示可查看完整选择。

导入完成后显示原件保存结果，再选择打开编辑。当前编辑器存在未确认草稿时，先按移动编辑工作区规则处理，再切到新原件。预览文件不能冒充原件保存成功。

### 增量导入

导入工作区可切换「手动选片」和「增量导入」，记住这台相机的模式和传输设置。连接后读取存储卡清单。
增量页显示起算时间和按格式计数的候选，点一次导入冻结本次队列。首次起点为当天零点，可指定相机日期和时间。

- RAW 和 JPEG 以卡内实际可读文件为准。RAW + JPEG 将两种文件分别计入清单。
- JPEG 默认原样保存。调整后保存允许原尺寸或自定义长边上限与 1–100% 质量。完整接收并校验后才在手机处理，保存调整后的 JPEG。两种格式都沿用现有持久保存位置。
- RAW 和 JPEG 各自用成功批次中已保存的文件更新起点。合并导入时每种格式按各自起点判断。覆盖边界时刻的新增文件，对身份无法确认的边界文件校验内容后复用已有结果。换卡、边界无法核对、日期未知分别给出重新选起点或显式包含的操作。
- 断线或停止后从已登记任务继续。续传前复核媒体库中的已保存项，再按相机清单提供的存储标识和文件元数据唯一匹配待传项的当前句柄。待传项继续使用原队列和 JPEG 设置。手动选片或临时选择更早时间补传可以复用已保存文件。
- 调整 JPEG 前检查 HDR 增益图。遇到带增益图的 JPEG 时，任务保留已保存项，并提示原样保存。

## 联机拍摄

- 取景保持完整画幅。快门速度、光圈、ISO、曝光补偿组成常用参数条，显示相机实际读回值，点击打开当前合法值选择。
- 白平衡与对焦在「拍摄参数」面板；色温仅在机身提供且允许时开放。构图网格、拍后审片、保存位置收在更多菜单，最近照片在快门旁。
- 竖屏为取景、参数条、拍摄区。横屏为左侧取景与紧凑参数条，右侧快门和最近照片。短屏与大字优先保证快门、参数和返回可达，低频内容滚动或展开。
- 参数读取中显示读取状态；不可写项显示具体原因，例如当前模式由相机控制；不猜测合法值，不把未知焦点编码标成 AF-S。
- 参数更新与快门、读卡共用串行调度。用户选择后写入一次，读回确认并刷新关联参数；拒绝和超时不伪装成功、不自动重复写入。导入 profile 不发送拍摄参数写入。
- 当前设计覆盖静态单拍，不在这轮增加视频、连拍、B 门或持久相机预设。

## 关键状态

| 状态 | 用户可见行为 |
| --- | --- |
| 无设备／未授权 | 给出当前原因、系统权限或相机设置入口与重试 |
| 连接中 | 标明目标相机，可取消；取消后旧结果不再进入工作区 |
| 可浏览／已连接 | 显示相机身份、当前任务及可用动作 |
| 参数读取／写入中 | 保留旧读回值并显示进度；完成后更新，不提前显示已成功 |
| 参数只读／不支持 | 保留已知读数及原因；不提供无效选择 |
| 拍摄结果未知 | 明确提示等待或检查相机；用户重新决定，不自动补拍 |
| 回传中／失败 | 显示队列与原件状态，成功项保留，失败项可以重试 |
| 断线／后台恢复 | 最后画面明确标记；关闭旧连接，恢复时重新选择或显式重连 |

## 设计资产与边界

`prototype/workspaces.html`、`.css`、`.js` 是本版源文件，复用已有照片素材和编辑工作区的图标子集。原型模拟相机与参数，不访问设备、不保存凭据、不写入媒体库。普通竖屏、大字、短屏、入口、连接、二级说明、未验证机型尝试连接、选择、参数选择和断线示意可审核；复杂错误、横屏和平板尚需补足原生实现后的验证。

这一版借用泼辣的内容仅限编辑工作区的任务边界，相机页不复制其其他产品功能。首台后续参数实测机型由用户选择 α7C II；ZV-E10 单独记录，不能从另一 Sony 机型推断通过。

审核通过后，按「导航与独立入口 → 选片布局 → 联机参数与状态 → 原生交互验证」推进。参数是否可写和 JPEG 镜头校正是否生效，必须用真实调用链、共享核心测试及设备证据确认，不能用本原型截图替代。

联机页的四参数条以具体读回值为主：快门时间、f 值、ISO 和曝光补偿，不用参数说明替代数值。参数名称在点开后的选择页显示；未读到值时使用占位，不推测相机设置。
