# Sony 相机导入：移动端 UI 与交互

版本：r4，2026-11-09。状态：Android 正式接入已实现；iOS/iPadOS 仍为设计提案。
Sony α7C II / 固件 2.00 已在 Pixel XL / Android 10 上验证产品内连接、RAW 选片导入、编辑及集合交接。
以下跨平台与宽窗口设计仍需按平台落地验证，不能视为所有平台均已实现。

[打开移动端原型](prototype/mobile.html) · [Mac 方案](ui-interaction.md) · [协议与存储合同](sony-wifi-design.md)

## 1. 延续的任务，改变的操作方式

主场景继续是用户确认的「挑选几张，再导入编辑」。移动端使用全屏导入流程，筛选和次要动作使用
系统菜单或底部面板，大图预览使用独立页面。保留 RawLab 深灰工作区与黄色功能色，不增加全局「相机」标签页。

手机不采用桌面的双击、Shift 选择或三栏布局：

- 点照片勾选，再点取消；照片下方有独立的放大按钮，点击目标与选中区域分开。
- 默认两列，让用户能判断构图并读清文件名。图片完整适配，不裁掉竖幅画面。
- 日期、文件类型与「只看已选」收进顶部筛选；底部固定显示已选数量、总大小及「导入 N 张」。
- 导入开始后进入进度页。返回照片页不取消任务；切到其他应用与退出导入页面是两种不同事件。

## 3. 连接：用最少步骤进入照片

2026-11-10 的 [Android 工作区设计](android-camera-ui.md) 增加独立「如何连接」二级页，并按用户要求取消已验证机型／固件清单的准入作用。其他 Sony 机型可以被发现、选择和尝试连接，功能按实际协议与能力结果分别开放。下面的精确机型范围描述首版实现现状，不是新的产品门禁。

Android 首版已实现并通过真机验证的路径：蓝牙发现与配对 → 获取相机提供的 Wi-Fi 参数 →
确认热点正在广播 → 系统连接确认 → PTP/IP 核对型号与固件 → 卡内列表。用户不手填 IP、SSID 或密码。
该首版最初仅开放 Sony α7C II（ILCE-7CM2、固件 2.00）。后续工作区已接入另一独立 profile；源码仍存在精确机型限制，须在新版设计实施时调整，不能继续用未实测作为拒绝连接的理由。

1. 从“从相机导入”进入连接页，展示打开相机“智能手机连接”的简短说明和“查找相机”。
2. 点击查找时按 Android 版本申请发现权限。Android 12 及以上申请蓝牙扫描和连接权限，较早版本申请精确位置。拒绝后保留重试和设置入口。
3. 显示找到的相机，由用户选择。选择相机时申请连接所需的 Wi-Fi 权限。系统 bond 及相机屏幕上的数字确认由系统与相机负责。
4. 协商 BLE 包长并完成 Sony 初始化后，读取 Wi-Fi 参数；参数只留在内存，不写日志或持久清单。
5. 取得目标热点的新扫描结果后发起 `WifiNetworkSpecifier`，系统负责连接确认。
   没有互联网不等于连接失败；相机 socket 只绑定此 `Network`，不全局绑定进程网络。
6. 在实际连接上核对型号、固件及手机 profile 后显示照片。再次连接复用已有系统配对，但仍尊重系统网络确认。

API 29 以下不能使用本次已验证的自动 Wi-Fi 路径，入口说明系统版本限制并保留系统文件导入。
不自动回退到 PC Remote、关闭认证或改变相机的网络配置。
连接失败明确区分权限、蓝牙关闭、没有热点、网络断开、没有对应协议适配、认证失败和协议错误，提供相应重试动作。
系统确认窗口属于交互等待，不把它当成协议数据超时；已开始的数据操作仍有超时和取消。

iOS 自动加入 Wi-Fi 需要签名支持 Hotspot Configuration 与 Access Wi-Fi Information。
默认签名可由 Personal Team 使用，用户从系统 Wi-Fi 设置加入相机热点后回到应用继续。
具备能力的团队可以[启用相机 Wi-Fi 签名配置](../../guides/ios-installation.zh-CN.md)。
原型中的权限界面只表达应用状态，不伪造系统授权窗口。

## 4. 挑选与大图预览

照片页顶部只保留返回、标题和更多动作。相机行显示「α7C II · 已连接」、卡槽和当前格式数量。
不把固件、端口、协议名称放进日常挑选界面。

```text
返回              从相机导入                 更多
α7C II                         已连接
存储卡 1 · 10 张 RAW
RAW / 全部日期                  查看已选 3

今天 · 11 月 8 日
[照片 ✓]                        [照片]
DSC04101.ARW  放大              DSC04102.ARW  放大
RAW · 46.3 MB                  RAW · 41.8 MB

已选 3 张 · 137.6 MB                         清空
                 [ 导入 3 张 ]
```

筛选面板中的改动先留在草稿，点「显示 N 张照片」才应用；关闭则保留原筛选。筛选不清空选择，
有隐藏的选中项时底栏明确显示数量。「查看已选」临时显示全部已选项，返回时恢复原筛选。

照片下方显示文件名、格式和大小。已保存项增加勾号与「已导入」，不只用颜色区分。
未知大小显示未知，未读完清单显示「已找到 N 张」，不把暂时数量当作存储卡总量。
缩略图按可见范围请求，失败时保持原位置，显示「预览不可用」，仍可导入原文件。

放大预览以照片为中心，底部显示文件名、格式、大小和「选中 / 取消选中」。
提供上一张/下一张按钮，左右滑动是额外快捷方式。iOS 左边缘留给系统返回，Android 系统返回先退出预览。
预览只读取相机提供的预览图，不为浏览一张照片预先下载整个 ARW；原文件在用户点击导入后才传输。

## 5. 导入、离开与恢复

点击导入立即冻结本次队列，按顺序传输。进度页展示当前照片、已保存数量、实际字节进度和逐张状态。
相机照片不会删除。用户可以返回照片页，页内显示正在进行的任务入口，重新进入可查看详情。
正在运行的同一相机会话不接受新一批选片；完成后继续挑选。

| 用户动作或事件 | 保留什么 | 页面如何回应 |
| --- | --- | --- |
| 返回照片页 / 返回 RawLab 编辑器 | 当前任务和已保存原件 | 应用仍在前台时继续导入；保留可见任务入口 |
| 点击「停止导入」 | 已完成文件、未完成项及选片 | 立即停止；显示「继续未完成」「查看已导入」 |
| 相机休眠、断网 | 已完成文件、选片与任务快照 | 显示「相机连接已断开」；重新连接后只继续未完成项 |
| 切到其他 App 或锁屏 | 已发布原件与恢复记录 | 首版不承诺持续后台接收；回来显示「上次导入未完成」 |
| 应用进程被系统终止 | 已发布原件与恢复记录 | 下次提供「继续导入」「仅查看已导入」，不自动切换当前照片 |
| 当前文件未完整保存 | 保留任务，不保留其临时字节作为可编辑原件 | 继续时从该文件开头重新下载，不称为按字节断点续传 |

进度页只出现一次清楚的提示「导入时请保持 RawLab 在前台」。前台活跃传输可临时避免自动休眠，
结束、停止或离开活跃状态后恢复；不要求用户关闭系统省电保护。
Android 首版同样采用前台合同，不提前展示通知权限或承诺前台服务下载；以后另行实现时再更新本设计。

完成状态就地呈现：

- 单张成功：显示照片和「打开编辑」。
- 多张成功：显示已保存缩略图与数量，「加入选片集合」复用已有批量编辑入口。
- 部分失败：「已导入 2 张，1 张未完成」，可重试未完成项，也可先编辑已导入照片。
- 相同内容已在本机：复用原件和已有调整，清楚显示「已在本机」；不因同名直接跳过读取。
- 已保存但不能编辑：保留原件，显示格式限制及可用的系统文件导出动作，不假报传输失败。

移动端的默认持久目录由应用管理，不在每次导入前打开系统目录选择器。
「导入记录」可离线查看和重新编辑；查看记录不要求相机连接或系统相册权限。

## 6. 与既有编辑器交接

进入相机页不代表要替换当前照片。只有点「打开编辑」或确认集合中的单张编辑时，才执行
当前编辑保存与几何/镜头草稿门禁。选「继续编辑」只取消本次跳转，下载成功的照片继续保留。
不能把相机传输直接挂到现有照片解码的 `importing` 标志上，导致整个编辑器在传图时不可操作。

| 平台 | 现有入口与合同 |
| --- | --- |
| iOS | [ContentView+Panels.swift](../../../RawLab/RawLab/UI/Editor/ContentView+Panels.swift) 的导入菜单/空态；[IOSBatchSelectionView.swift](../../../RawLab/RawLab/UI/Export/IOSBatchSelectionView.swift) 的集合；[ContentView+Helpers.swift](../../../RawLab/RawLab/UI/Editor/ContentView+Helpers.swift) 的草稿离开门禁 |
| Android | [EditorPanels.kt](../../../RawLabAndroid/app/src/main/java/com/rawlab/android/editor/ui/EditorPanels.kt) 与 [EditorScreen.kt](../../../RawLabAndroid/app/src/main/java/com/rawlab/android/editor/ui/EditorScreen.kt) 的导入入口；[BatchSelectionScreen.kt](../../../RawLabAndroid/app/src/main/java/com/rawlab/android/batch/ui/BatchSelectionScreen.kt) 的集合；[EditorViewModel.kt](../../../RawLabAndroid/app/src/main/java/com/rawlab/android/editor/EditorViewModel.kt) 的保存/草稿/后台处理 |

iOS 原文件放独立持久区，编辑工作副本仍按既有生命周期管理。Android 相机原件进入系统媒体库，
使用具体媒体卷的 Images URI；已登记相机媒体的聚合 URI 别名统一到该身份，相同字节复用原件和调整。
这些 UI 不能直接绑定临时下载路径，也不能把相机原件加入现有 working-copy 清理范围。
完整身份规则见 [文件事务](sony-wifi-design.md#63-文件身份发布事务与崩溃窗口)。

## 7. 平板、横屏与可访问性

布局根据可用窗口宽度而不是设备型号变化：

- 窄窗口保持手机结构，两列网格；极窄或辅助功能大字改为一列图文行，完整显示文件名。
- 宽窗口约 700 pt/dp 起使用日期侧栏和三至四列照片；操作栏仍贴内容区底部，主要按钮不无限拉长。
- iPad 筛选用锚定 popover，紧凑窗口回退 sheet；Android 展开窗口使用侧面/底部筛选面板，尊重当前窗口与折叠铰链。
- 横屏减少顶部说明，保留可滚动内容和固定操作栏；键盘出现时用原生 safe-area / IME inset 避让认证字段。
- 选中状态同时具备勾号、轮廓和可访问名称；尺寸、文件名和选中状态按项朗读。进度只播报有意义的阶段，不逐包播报。
- 尊重 Reduce Motion / Remove animations。照片切换与面板动画服务于导航，不使用装饰动画。

原型提供 iPhone / Android 对照、单平台、平板和大字模式，以及连接、选片、预览、进度、后台恢复、
断线、部分失败、完成与连接受限场景。它用浏览器表达原生设计，不构成模拟器或真机上的实现证据。
原型不代表实际权限或网络验证。iOS 与 Android 产品均已接入；iOS 相机硬件验收仍待真机签名与实连。

## 8. Android 实现边界

本轮选择 Android 原生接入：保留已验证的 Java PTP/IP 行为，拆出平台无关协议层，
Kotlin 层处理 BLE、网络权限、会话生命周期、持久队列和 Compose 界面。
先抽四端 C ABI 会把尚未验证的 iOS/Windows 平台约束带进当前交付，因此留作后续跨端工作。

原件保存到系统媒体库，目录和每张照片的拍摄日期分组遵循 [Android 媒体库设计](android-media-library.md)。
应用私有目录只保存相机任务清单、媒体摘要记录和可清理缓存，不为新相机导入保留第二份长期原件。
文件从独立 partial 暂存完成协议校验后写入待发布媒体项，完整校验后才发布，清单记住保存结果与 URI。
重启时保留已保存文件，将未完成项标记中断，删除本任务 partial；恢复时重新列卡并核对快照，
只重传未完成项，不沿用旧会话 locator，不提供按字节续传。
蓝牙引导和手动 Wi-Fi 之间切换后，可用 PTP 相机序列号和型号确认同一设备，并逐项核对
待传文件后继续原任务。只记录了连接标识的旧任务须从原连接方式恢复。
相机导入不会扫描或迁移其他系统来源；通过相同内容摘要命中仍有效的已登记媒体时复用其编辑身份。
旧测试版原件与记录不迁移、不删除；其他外部 provider 的既有私有持久输入行为保持不变。

“打开编辑”或“加入选片集合”复用 `receiveSystemPhotos` 的排队、持久输入与草稿门禁。
进入相机页不提前应用/放弃几何草稿；编辑器页面状态在相机页往返时保留。
完成页的“在相册中查看”进入现有相册并筛选本次照片；选择照片或从该页面选择文件后才触发草稿门禁。
日后可直接从相册重新打开。没有全库权限时仍显示自有媒体，同名日期目录按实际路径区分。
相机传输状态独立于图像解码的 `importing`，错误与统计中不包含相机凭据或照片内容。

缩略图与放大图使用 `0x923E`，只请求可见项；缓存有界，下载优先于预览请求。
缩略图失败显示占位并保留导入能力，不偷偷下载完整 RAW 生成预览。
正式 Android 接入已完成选片、多张队列、停止/进程重启恢复、后台暂停、重复导入、单张编辑与多张集合的模型和真机验证。
真机范围限 Pixel XL / Android 10 与 Sony α7C II / 固件 2.00 的 RAW 路径；JPEG 原件传输尚未实测。
后台行为是暂停后重连恢复，不承诺持续下载或按字节续传。蓝牙连接失败时可重新查找，不保证每次重连无需重试。


## iOS 原生接入

iOS 使用 CoreBluetooth 发现与能力允许的配对，通过系统 Hotspot Configuration
或用户已连接的 Wi-Fi 取得真实网关。PTP/IP、现代手机内容协议和 legacy 内容协议
由 Swift 单会话 worker 串行处理；实时取景独立接收。网络和蓝牙授权不等于已连接相机。

原件保存在应用持久区，经完整长度、格式头和 SHA-256 校验后原子发布。
导入任务与联机请求先登记，后台和锁屏暂停；恢复只接续已登记原件，
断线期间未登记的照片需手动导入。收到快门确认不等于照片已保存，未知结果不会自动补拍。
编辑入口只接受已再次校验的完整原件，工作副本沿用既有编辑生命周期。

型号与固件清单只记录实测范围。导入、取景、快门和参数写入按连接后实际协议能力分别开放，
缺少某项能力不会伪造可用状态。iOS 模拟器可验证导航、权限前置界面与编辑交接模型，
不能证明相机 BLE/Wi-Fi、取景和曝光硬件链路已通过。
