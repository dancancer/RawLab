# Android 相机原件与系统媒体库

日期：2026-11-09。范围：Android 10+ 的相机导入。测试版旧数据不迁移、不删除。

本文定义实现契约和验收要求；当前设备与格式支持范围见 [Android README](../../../RawLabAndroid/README.md#功能--features)，单次验证证据随对应变更记录。

## 用户目标

相机照片保存到系统媒体库的可配置目录，RawLab 和获得授权的其他应用读取同一份原件。
用户以后从 RawLab 现有相册继续编辑，无需回到相机导入记录，也无需重新连接相机。
相机中的原片保持不变；编辑参数独立保存，导出不会覆盖原件。

## 保存与目录

- 默认位置为 `Pictures/RawLab/Camera/`，用户可修改 `Pictures/` 下的目录名及子目录。
- 分组可选：统一目录、按拍摄日、按拍摄月份。默认按拍摄日。
- 日目录形如 `2026-10-22`，月目录形如 `2026-10`；日期来自每张原片的拍摄元数据。
- 按原片 `DateTimeOriginal` 的日期字段归档，不按手机当前时区换算，不使用导入时间、
  文件修改时间或含义未确认的相机列表时间代替。缺失/非法日期进入 `Unknown date`；界面使用本地化提示。
- 同一批不同拍摄日期可以进入多个目录。开始任务时冻结目录设置，跨日续传仍使用同一规则。
- 设置变化只影响新任务，不移动已保存照片。导入前显示目录规则和示例；完成后显示实际位置。
- 保留相机文件名与扩展名；同目录同名不同内容时自动加序号，不覆盖。

## 原件与任务事务

应用私有空间只保留任务/去重记录、调整和必要可清理缓存，不为新相机导入长期保存第二份原件。
完整下载先校验长度、文件头与摘要，再写入系统媒体库待发布项，校验完成后发布。
只有已经发布且仍可读的照片计入成功项。中断保留已发布项，未完成文件从头重传。
发布前后的崩溃窗口由任务清单恢复；只清理本功能创建且未发布的记录，不清理其他应用或已发布照片。

重复导入在本功能已有记录中按内容摘要查找，复用前校验当前媒体内容。
已有原件仍有效时复用其媒体身份、位置和编辑，不因新目录设置生成另一份。
已有记录被外部删除/修改时，不覆盖或悄悄恢复；新导入可创建新的媒体项。
打开记录中已变化的原件时明确报错，避免给替换后的照片套用旧调整。
重启或打开失败后复核原件，不可用项不计入完成数量；用户主动重新下载时创建新的媒体项，
任务保留原来的不可用引用，不覆盖外部修改的文件。

## 编辑身份与相册

- 新相机原件以具体媒体卷的 Images URI 为稳定身份。
- 相册聚合查询返回的 `external` 别名、导入结果及系统分享必须在确认是已登记的相机媒体项后归一化。
  现有其他照片的编辑键和任意外部 provider 的持久输入行为不扩大改造。
- 从系统媒体库打开已登记相机照片时不再复制到私有 `system-photos`。
- 即使没有读取整个相册的权限，仍显示本应用有权读取的自有媒体；其他媒体按系统授权展示。
- 相册按实际媒体卷/目录区分，同名日期目录不能混为一组。
- 完成页提供“在相册中查看”，定位本次已保存照片；同时保留立即编辑和加入选片集合。
- 从该相册视图选择新照片仍经过现有草稿门禁，不提前放弃当前草稿。
- 原件外部移动/改名但媒体身份保持时继续关联；媒体身份失效时提示无法访问，
  不凭文件名搜索整机或自动关联其他文件。

其他相册应用的目录显示形式及 ARW 缩略图能力由该应用决定；媒体库可访问不等于所有应用能显影 RAW。
RawLab 的调整只在本应用中生效，卸载应用后原件仍在，调整记录不因此成为系统级备份。
Android 可以对非所有者应用读取的定位元数据脱敏；原件写入完整性以保存者 UID 的读取校验为准。
跨应用读取不能据此绕过系统的位置隐私权限，也不能把脱敏后的摘要差异当作原片被改写。

## 接入选择

采用系统媒体库作为新相机原件的唯一持久位置，继续使用现有相册和编辑器。
不采用“私有原件再额外复制到媒体库”，因为会占用两份长期空间并造成入口身份分裂。
任意文件系统/外置卷选择、自由表达式命名规则和旧测试数据迁移不在本次范围。

## 验收

1. 同批跨拍摄日期照片正确分目录；手机时区变化、跨日续传和设置变化不改变已有任务规则。
2. 真实 MediaStore 上校验 pending/发布、同名冲突、重复内容复用、中断与发布后崩溃恢复。
3. 相机结果、相册、媒体库别名分享进入同一编辑身份，重新打开恢复已保存调整。
4. 无全库读取权限仍显示自有照片；不同目录的同名日期组正确区分。
5. 本机文件应用/另一应用能读取真实导入的 ARW，字节数与摘要保持一致。
6. 外部删除/替换原件后明确提示；旧测试版私有数据和其他项目资源保持不变。
