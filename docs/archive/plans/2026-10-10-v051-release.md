> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Architecture:** Work in the existing isolated worktree. Preserve the published v0.5.0 release by backmerging it before integrating the feature, then build all client assets from the versioned release tree. Tag the merged `main` commit and backmerge the release to `development`.

- Keep Auto fallback, actual-backend Force assertions and existing processing semantics.
