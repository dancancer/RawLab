# RawLab v0.4.1 Release Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to execute the release steps below in order.

**Goal:** Publish the scoped RAW compatibility fixes as v0.4.1 after PR verification and merge.

**Architecture:** Isolate the release from the dirty development checkout. Rebuild each client from the same scoped source tree, retaining the shared LibRaw 0.22.2 patch and existing platform packaging conventions.

**Tech Stack:** C++17/LibRaw, Swift/Xcode, Kotlin/Gradle, WPF/.NET and Windows MSVC.

**Spec:** `docs/verification-raw-compatibility-2026-10-09.md` and the user's approval to commit, create/merge a PR and publish v0.4.1.

## Global Constraints

- Exclude unrelated batch export, edit persistence and RAW denoise work; preserve the original checkout.
- Version 0.4.1, build 7; macOS 15+, iOS 18+, Windows x64, Android SDK 26+.
- Preserve Android release signing identity; Mac remains ad-hoc signed and iOS remains unsigned.
- Nikon HE* remains unsupported; do not claim physical iOS or VM Direct3D hardware validation.
