## Release Fixes

The fix is committed as [24a8191](https://github.com/dancancer/RawLab/commit/24a8191).
The CPU continuity regression failed before implementation, then passed after
the shared fix. Hue-dependent lightness fades below an RGB channel spread of
`1/255`; hue/saturation and ordinary-color lightness remain unchanged. CPU,
Metal, GLES and D3D11 use the same formula. No comparison threshold was relaxed.

The initial Mac smoke incorrectly compared two `.preview` configurations after
the application's default changed. It now explicitly compares `.scene` and
`.preview` and checks restoration. Android's standalone RAW/proxy phase had
inherited active filters from the combined synthetic phase, which correctly
disabled proxies; it now keeps the strong real-RAW combination check and uses
independent sessions for the baseline/proxy tests. PNG dimensions are checked
against native RGBA geometry instead of assuming a landscape fixture. Initial
failed logs and post-fix passing logs are retained separately.

## Release Assembly

The verified release branch merges to `main` through a PR. The merged tree must
equal the built release tree before tagging `v0.6.0`. Corresponding-source
archives include pinned native dependency sources and actual patched LibRaw;
`BUILD-PROVENANCE.json` identifies source/built commits, tree and dependency
hashes. `SHA256SUMS.txt` covers the seven payload assets. Upload verification
compares all eight remote asset sizes and digests before publication. Release
changes return to `development` through a PR; final remote operations are
evidenced by the PRs, tag and GitHub Release rather than a later source edit.

Local ignored evidence is under `build/releases/v0.6.0/logs/` and `assets/`, with
Windows transfer logs under `build/windows-remote/`. These are local results,
not GitHub CI results. See [release notes](../../../releases/v0.6.0.md),
[source rebuild instructions](../../../releases/v0.6.0-source.md) and [licensing](../../../licensing.md).

## Remaining Limits

- No GitHub Actions workflow is configured; empty PR checks are not passing CI.
- iOS device output is unsigned. Physical iPhone/iPad installation, GPU behavior,
  memory and thermals are untested; simulator Metal is not physical coverage.
- Mac apps are ad-hoc signed, not notarized. Native Intel hardware and physical
  macOS 15 remain untested; Intel execution here uses Rosetta.
- The Android signed Release APK is not installed on the device. Fresh Release
  native GLES executables run independently; JNI/recipe and UI evidence uses
  temporary debug instrumentation. Actual signed-package installation and
  upgrade migration are untested; signing continuity is checked by certificate.
- Windows Explorer desktop interaction is not certified. Low-memory devices,
  every camera mode and comparative GPU speedups are not covered.
