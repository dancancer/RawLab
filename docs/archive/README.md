# Historical Records

These records span release iterations, multiple PRs or cross-feature integration.
Their dates, source revisions, results, unchecked tasks and limitations retain
their original scope; archiving is not a new acceptance result. Only relative
references are adjusted when records move.

Single-change plans, verification logs and redundant navigation wrappers are
available through Git history, not retained here. New per-PR evidence belongs
in PR descriptions under the [documentation policy](../../agent.md#文档).
See the [documentation index](../README.md) for current references and active work.
