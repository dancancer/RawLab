# Historical Records

This archive retains cross-PR release, integration and review records. Dates,
source revisions, results and limitations retain their historical scope;
archiving a record does not certify its unchecked tasks. Use the
[current documentation index](../README.md) for active work.

Single-change plans, verification logs and their old navigation wrappers are
removed from the current tree. Historical evidence links use the immutable Git
revision that still contains the original record. New per-PR evidence belongs
in PR descriptions, as defined in the [development process](../../agent.md#文档).

Some records reference ignored local build logs, generated comparisons or
packages that are absent from a clean checkout. These references retain their
original locations and do not establish current verification results.
