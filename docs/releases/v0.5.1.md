# RawLab v0.5.1

Cross-platform photo effects and GPU denoising, version `0.5.1`, build `9`.
All four clients retain the v0.5.0 features and shared LibRaw 0.22.2 patches.

## What's New

- iOS, Android and Windows now provide the same vignette and deterministic
  grain controls as macOS: five vignette parameters and three grain parameters,
  with matching defaults, ranges, rounding and reset behavior.
- Wavelet and display-chroma filtering use Metal on macOS/iOS, GLES 3.1 on
  Android and D3D11 on Windows. Auto retains CPU fallback; Force reports
  required GPU failures instead of labeling CPU output as GPU.
- Preview, final export, per-photo edit memory and batch jobs carry complete
  effects/denoise state. Older records default to effects off; grain retains
  fixed full-image coordinates and a shared hash.
- Windows effects controls reflow at narrow editor widths and remain scrollable
  so vignette labels and lower parameter rows are not clipped.
- The repository adopts Gitflow: feature PRs target `development`, versioned
  release branches merge to `main`, and release changes return to `development`.

Noise estimation/calibration, OpenCV Lab conversion, outer filters, RAW
development and file encoding remain CPU work. This is not an all-GPU RAW
pipeline. GPU numerical comparisons use explicit tolerances, not a promise of
bit-identical pixels across drivers.

## Signing and Limits

- Android retains the existing release signing identity for upgrades from
  earlier release-signed packages; it cannot replace differently signed debug apps.
- Windows is unsigned. Tests assert actual D3D11 execution on the available
  adapter; the adapter's display name alone does not establish compute support.
  Explorer desktop integration and comparative GPU performance are not certified.
- Mac applications are ad-hoc signed and not notarized. Intel execution uses
  Rosetta, not native Intel hardware; physical macOS 15 coverage is outstanding.
- **The unsigned iOS IPA cannot be installed directly.** Re-sign the application
  and embedded framework with a valid certificate and provisioning profile.
  This is not an App Store/TestFlight distribution. Simulator Metal checks do
  not establish physical iPhone installation, GPU behavior, memory or thermals.
- Low-memory devices and every camera mode are not covered. Nikon HE* samples
  previously documented as unsupported remain rejected rather than exported
  as damaged images. X-Trans retains its eight-byte-per-pixel temporary copy.
- No GitHub Actions workflow is configured. Local tests are not CI results.

Original project code remains `GPL-3.0-only`; third-party and historical notices
are retained. Personal RAW files, private signing material and build credentials
are excluded from distributed source and client packages.
