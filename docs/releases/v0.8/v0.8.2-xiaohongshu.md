# RawLab 0.8.2 更新内容

- 新增 DCP 色彩配置文件直接导入，Mac、Windows、iOS 和 Android 四端均可使用。
- 扩展 RAW 兼容性，支持尼康 HE/HE*、索尼 ARW6，补齐适马 X3F 和 JPEG 压缩 DNG 的读取。
- 优化胶片外观处理，以及裁剪、旋转和透视调整的预览速度。
- 修复 Windows 部分 JPEG 无法导入、首次预览颜色异常的问题。
- 优化 iOS 普通图片预览和导出，降低单张导出的内存占用，修复文件读取异常。
- 提升 Android 批量导出的稳定性，优化任务恢复和进度保存。
- 继续完善多语言文案、错误提示和无障碍标签。
