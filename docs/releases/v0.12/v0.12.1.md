# RawLab 0.12.1

Version `0.12.1`, build `24`.

This is a **mobile-only release for Android and iOS** delivering editor
workspace polish, loading-feedback fixes, and camera import / wireless
tethering UI refinements from PR #628 and PR #637 on top of `0.12.0`.
**macOS and Windows desktop packages remain at `0.12.0` (build `23`)** and are
not republished here.

## New and improved

### Mobile editor workspace and loading feedback (iOS & Android)

- **Unified bottom tool rail and panel hierarchy**: Shared surface/tonal cards,
  collapsible adjustment presentation, consistent Apply/Cancel panel controls,
  and refined tool organization across both iOS and Android.
- **RAW loading indicator hygiene**: Fixed RAW loading banner feedback on
  iOS and Android so interactive slider adjustments no longer trigger distracting
  loading overlays during active drags (`isAdjustingSlider` /
  `EditorInteractionState`).
- **Look-deletion semantics parity**: Deleting an imported look on iOS now
  removes only the look library entry (matching macOS behavior and preserving
  unsaved/committed photo adjustments without mutating photo settings behind the
  tool panel), and look deletion is disallowed while a tool draft panel is
  open (matching Android).

### Camera import and wireless tethering UI polish (iOS & Android)

- **Simplified manual JPEG sizing controls & tonal cards**: Cleaner hierarchy
  for Sony camera connection, incremental import, and manual browser views
  across iPhone, iPad, and Android phones/tablets.
- **Adaptive 3/4/5-column photo grid**: Responsive grid column density aligned
  across compact and regular/tablet viewports (`IOSCameraLayoutPolicy` /
  `cameraGridColumns`), plus accessibility large-text / font-scale legibility
  and full contrast on prominent action buttons.
- **Bottom-sheet tethering parameter pickers**: Camera shooting/tether options
  open in structured bottom sheets with positional selection keys and live busy
  progress feedback; removed stale manual Wi-Fi copy that previously referenced a
  deleted top section on iOS.

## Upgrade and compatibility

- **Android**: The signed APK retains the existing `0.12.0` release signing
  identity and can update `0.12.0` (or `0.11.x`) release builds in place.
- **iOS**: The supplemental unsigned IPA requires valid user signing and
  provisioning before installation and is not an App Store or TestFlight
  package.
- **macOS & Windows**: Desktop packages are unchanged at `0.12.0` (build `23`).
- Edits and the `0.12.0` data format are unchanged. Downgrading to `0.11.x` or
  earlier remains unsupported; see the
  [0.12.0 compatibility notes](v0.12.0.md#compatibility-and-known-limits).

Download `RawLab-Android-0.12.1.apk`, `RawLab-iOS-0.12.1-unsigned.ipa`, and

desktop update metadata (`appcast-arm64.xml`, `appcast-x86_64.xml`, and

update checks continue to resolve against the unchanged `0.12.0` macOS and
Windows packages.
