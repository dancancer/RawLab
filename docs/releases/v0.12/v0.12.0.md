# RawLab 0.12.0

Version `0.12.0`, build `23`.

## New and improved

- **Tone Curve v2 (all four clients + CPU/Metal/GLES/D3D11)**: Unrestricted endpoint Y coordinates (`y0` matte fade / `y1` highlight compression) with monotonic PCHIP interpolation, a **Luminosity** curve mode that scales RGB by linear luminance ratio with gamut protection, 4-band **Parametric Curves** (Highlights / Lights / Darks / Shadows with 3 adjustable split points), full `R/G/B` channel tabs on macOS and Windows, and on-canvas targeted curve dragging. Channel curves now execute directly on Metal, GLES, and D3D11 GPU backends without Force GPU fallback errors.
- **Color Grading v2, White Balance Eyedropper & Raster Relative WB**: Per-zone **Luminance** controls for Shadows, Midtones, and Highlights, a **Global** color wheel, **Blending** and **Balance** controls, on-canvas **WB Eyedropper** (`sony2fuji_session_sample_wb_probe` with blown-channel rejection), and **SDR Raster Relative WB** for JPEG/PNG/TIFF/HEIF across all four clients.
- **Desktop DualDn AI Denoise Blend (0–100%)**: Continuous AI denoise strength slider on macOS (Apple Silicon) and Windows that interpolates cached camera/scene linear residuals in real time without re-running neural inference.
- **Quantitative Sampling & Non-Destructive Inspection Suite (all four clients)**: Live local-mean `RGB (0–255) + HSB (H°, S%, B%)` probe, histogram luminance cursor, up to 4 pinned comparison anchors that follow geometry edits, and 5 non-destructive viewport inspection layers (Sketch Luminance, Warm/Cool B&W Contrast, Oversaturation Thermal Map, Skin-Hue Zoom, and 50% Neutral Gray Rest Overlay) guaranteed zero-impact on recipes and exports.
- **Color Delivery & Export Hardening**: Real `sRGB IEC61966-2.1` `APP2 ICC_PROFILE` embedding in JPEG exports, deterministic coordinate-hashed 8-bit dithering eliminating gradient banding, post-resize **Output Sharpening** (`Off / Low / Standard / High`), and lossless **16-bit PNG** export on iOS (single and batch).
- **Agent Telemetry, Desktop Hot-Reload & MCP Expansion**: Native memory-buffer B→S→H diagnostics (`sony2fuji_diagnose_image`, `sony2fuji_sample_region_bsh`), CLI `--analyze` / `--sample` / `--print-transfer`, desktop JSON adjustment transfer (`rawlab-transfer-v1.json`) with draft-safe non-intrusive hot-reload banner and single-step Undo, plus `rawlab_mcp` read-only `diagnose_image` / `list_catalog_looks` and gated GUI-sync tools (`--enable-gui-sync`).
- **Master Recipe Rendering Optimization & Android Sony Wi-Fi**: Metadata-only WB resolution, preview mosaic reuse, half-size proxy WB shortcuts, and fused GPU/CPU passes across RAW/GPU/CPU paths, plus Sony camera access authentication, dual-slot import, and MagicOS 9 Wi-Fi compatibility on Android.

## Compatibility and known limits

- Downgrading is not supported. Edits saved by `0.12.0` (including processing version `4`/`9`, Tone Curve v2, Color Grading v2, and output sharpening) are not supported by `0.11.x` or earlier.
- AI denoising requires a hardware GPU (Apple Silicon Core ML on macOS, DirectML/D3D12 on Windows) and the licensed DualDn/Restormer model package; there is no CPU neural-inference fallback. Intel macOS builds exclude AI denoising.
- Mac installers use the fixed self-signed certificate and Sparkle EdDSA signing (not notarized; first launch requires explicit approval via **System Settings → Privacy & Security → Open Anyway**). Windows automatic updates require the current-user Setup installer (`0.9.0` or later) and P-256 signed `windows-stable.json` (SmartScreen may require **More info → Run anyway**).
- The unsigned iOS IPA requires valid user signing and provisioning before installation and is not an App Store or TestFlight package.
- For camera import, HDR, ProRAW, X3F, and minimum-OS device coverage boundaries, see the [0.11.0 release notes](../v0.11/v0.11.0.md#compatibility-and-known-limits), [0.10.0 release notes](../v0.10/v0.10.0.md#compatibility-and-known-limits), and `BUILD-PROVENANCE.json` attached to the release.
