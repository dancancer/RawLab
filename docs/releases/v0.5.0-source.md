# Rebuilding RawLab v0.5.0

`RawLab-0.5.0-source.tar.gz` contains the project source from the `v0.5.0` tag and
pinned native dependency source archives under `dependency-sources/`. The
archive's `BUILD-PROVENANCE.json` identifies the exact source commit. GitHub's
automatic source archives contain the project tree without this dependency cache.

Dependencies keep their upstream licenses. Original RawLab code is distributed
under [GPLv3 only](../../LICENSE), with the [historical notice](../licensing.md)
retained. No signing keys, credentials or personal RAW files are supplied.

## macOS

Install Apple Command Line Tools, CMake, pkg-config and make. Copy the pinned
native dependency archives into the build cache, then rebuild each architecture:

```sh
mkdir -p build/macos15-deps/sources
cp dependency-sources/* build/macos15-deps/sources/
for arch in arm64 x86_64; do
    RAWLAB_ARCH="$arch" MACOSX_DEPLOYMENT_TARGET=15.0 bash RawLabMac/build-dependencies.sh
    RAWLAB_ARCH="$arch" MACOSX_DEPLOYMENT_TARGET=15.0 \
      PKG_CONFIG_PATH="$PWD/build/macos15-deps/$arch/install/lib/pkgconfig" \
      RAWLAB_BUILD_DIR="$PWD/lutools/build-macos15-$arch" \
      RAWLAB_APP_PATH="$PWD/build/macos15-$arch/RawLab Mac.app" \
      bash RawLabMac/build.sh
done
```

The scripts check fixed upstream archive hashes and apply the shared LibRaw and
wavelib patches from this release. They retain OpenMP, LCMS and JPEG/deflate
support for Mac LibRaw. GPU rendering, effects and denoising use the shared core.

## iOS

Use full Xcode with the iOS SDK, CMake and pkg-config:

```sh
mkdir -p lutools/build-ios-libraw/0.22.2/sources
cp dependency-sources/LibRaw-0.22.2.tar.gz \
   dependency-sources/LibRaw-cmake-eb98e43.tar.gz \
   dependency-sources/opencv-4.12.0.tar.gz \
   lutools/build-ios-libraw/0.22.2/sources/
cp dependency-sources/wavelib-7f61bf592f3c470b2a7d8199431fde821d7253ac.tar.gz \
   lutools/build-ios-libraw/0.22.2/sources/wavelib-7f61bf5.tar.gz
bash lutools/build.sh ios
xcodebuild -project RawLab/RawLab.xcodeproj -scheme RawLab \
  -configuration Release -sdk iphoneos -destination 'generic/platform=iOS' \
  -derivedDataPath build/ios-release CODE_SIGNING_ALLOWED=NO build
```

The framework is rebuilt for device arm64 and simulator arm64/x86_64 and
statically incorporates LibRaw and denoising dependencies. Distribution needs
your own certificate and provisioning profile. See the [iOS guide](../../lutools/platform/ios/README.md).

## Android and Windows

- Follow the [Android guide](../../RawLabAndroid/README.md) for SDK/NDK/Gradle
  requirements and release signing. Upgrading official packages requires the
  original signing identity, which is not supplied. The build scripts verify
  pinned LibRaw/OpenCV/wavelib downloads.
- On a prepared Windows x64 host, run `RawLabWindows/build.ps1 -SelfContained`.
  Native dependencies are downloaded from fixed source revisions and checked
  by hash. ExifTool's Windows distribution includes its Perl source and notices.
  See the [Windows guide](../../RawLabWindows/README.md).

For GitHub publication, copy the build outputs to versioned asset names:
`RawLab-Windows.zip` becomes `RawLab-Windows-0.5.0-win-x64.zip`, and
`RawLab-Android-release.apk` becomes `RawLab-Android-0.5.0.apk`. Verify those
names before uploading so the download links and platform update checks agree.

`LibRaw-0.22.2-patched-source.tar.gz` separately contains the actual patched
LibRaw tree and fixed LibRaw-cmake wrapper. Its `src/` matches the source used
by this release; the project archive supplies the full client/core code and
platform build scripts.
