# RawLab Mac v0.1

首个 macOS 桌面版本，提供跨品牌 RAW 显影、富士胶片 LUT 和桌面效果对比。

## 下载

- `RawLab-Mac-0.1-macOS-arm64.zip`：解压后得到 `RawLab Mac.app`，可拖入 Applications。
- `SHA256SUMS`：下载文件的 SHA-256 校验值。
- `LibRaw-0.21.5-source.tar.gz`：LibRaw 官方 `0.21.5` 标签的源代码归档。依赖说明、构建配方和许可证已随应用附带。

## 系统要求

- Apple Silicon（arm64），macOS 26 或更高版本。
- 未提供 Intel 或 Universal 构建。
- 已内嵌非系统动态库，不需要用户安装 Homebrew。
- 当前为 ad-hoc 签名，未进行 Developer ID 签名或 Apple 公证；macOS 可能阻止默认打开。没有要求关闭系统安全保护。也可以从此标签的源代码自行构建。

## 功能

- 中性显影与胶片效果并排对比，内置十种胶片模拟 LUT，也可导入兼容的 CUBE。
- RAW 相机空间白平衡、曝光、高光、阴影、对比度、曲线、饱和度和锐化调整。
- 可收起的目录树、照片缩略图、底部调整栏和悬浮 RGB 直方图。
- Metal 像素处理，拖动时快速预览，松手后恢复精确质量；GPU 不可用时回退 CPU。
- 原始尺寸 JPEG / 16-bit PNG 导出，不覆盖 RAW 原文件。
- 扁平双画幅应用图标和 README 功能截图。

## 验证与限制

- 本机 Apple Silicon 构建、核心回归、图标、动态依赖和应用签名检查通过。
- 发布包解压后的应用完成 Sony ARW / DJI DNG 显影与导出验证。
- RAW 去马赛克仍由 CPU 执行；交互快速预览不代表完整质量处理的速度。
- 本地样片覆盖不等于所有相机型号验证。胶片 LUT 输出不承诺与富士机内 JPEG 完全一致。
- 编辑参数目前仅保存在当前应用会话中，尚无跨会话编辑档案。
- 这是独立项目，不是 Fujifilm 官方应用。
