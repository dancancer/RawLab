# RawLab v0.4.0

本次发布包含 Windows 日期标识独立运行包、macOS 15 双架构应用和 Android 正式签名 APK。iOS 暂不重发，继续使用 [v0.2 未签名包](https://github.com/dancancer/RawLab/releases/tag/v0.2)，其中不包含后续源码更新。

2026-10-08 以构建 6 覆盖更新四个安装包，保留 v0.4.0 版本号和原下载文件名；Mac/Android 内部构建号为 `6`，Windows 文件版本为 `0.4.0.6`。已下载早先安装包的用户可重新下载并覆盖升级。

## 更新

- 构建 6 在 Mac、Windows、Android 增加“关于 RawLab”，包含 [GitHub 仓库](https://github.com/dancancer/RawLab) 和 [作者的小红书主页](https://www.xiaohongshu.com/user/profile/6474b1560000000010037c8e)。
- 启动后后台检查正式发布，每 24 小时最多自动检查一次；支持关闭自动检查及随时手动检查。只提示有本平台安装包的新版本，可查看更新说明并前往官方下载页；不自动安装、不上传照片，网络错误不弹窗打断编辑。
- Windows 选片先显示相机内嵌预览，再补齐 RAW 显影；双击立即放大并后台补齐原尺寸细节。重复缩放复用精确图像缓存，平移复用图像图层，支持远程桌面环境下的 WPF 硬件绘制。
- Windows 启用多核 RAW 处理，关闭对比或裁切提示时避免不必要的处理。导出仍须等待精确结果，并独立生成全分辨率成片。
- Mac 和 Android 增加持久化自定义外观库，支持 CUBE/RLOOK 的批量导入、重命名和删除。导入文件保存为托管副本，重启或删除外部原文件不影响外观；批量部分失败保留成功项，显示失败文件，选中最后成功项。
- Windows 的外观导入支持多选，但仍使用会话内的外部文件引用，不包含 Mac/Android 的持久化托管库和逐文件导入报告。
- Fuji F-Log/F-Log2/F-Log2C CUBE 可按声明的色彩约定直接使用；技术 Log 输出会解码为显示图像。共享核心增加对应 Metal、GLES 和 Direct3D 11 路径，Auto 在后端失败时回退 CPU。
- Mac 和 Android 对外版本为 `0.4.0`，构建号从首次发布的 `5` 递增至 `6`。

## 边界

- RAW 解码、去马赛克和文件编码仍在 CPU，并非全流程 GPU 显影；原生 DCP/RLOOK 的 GPU 路径限 Metal，Android/Windows 使用 CPU 回退。
- 可解析、可导入及 CPU/GPU 一致性，不代表完成所有相机的色彩标定或完整复刻 Fuji/Adobe/Lightroom 的输出。DCP 不替换目标 RAW 的传感器校准或白平衡，源 XMP 尚不能直接执行。
- 自定义外观导入接受准备好的 CUBE/RLOOK，不直接执行源 DCP/XMP；制备方法见 [LUT 准备文档](https://github.com/dancancer/RawLab/blob/v0.4.0/lutools/docs/lut-preparation.md)。
- 私人 RAW 样片、Adobe profiles 和派生测试外观不随应用分发；Windows 随附的 ExifTool 官方发行目录保留其自带测试资源。
