# RawLab v0.4.1

RAW 兼容性修复版，四个平台统一使用带补丁的 LibRaw 0.22.2，构建号为 7。

RAW compatibility release. All four platforms use patched LibRaw 0.22.2, build 7.

## 修复 / Fixes

- Panasonic S5 II 等 encoding 8 RW2 不再被旧解码器错误处理为噪点。
  Decodes Panasonic encoding 8 RW2 instead of routing it through the older decoder.
- 修复 Canon R6 III 特定 ColorData 布局和色彩矩阵，避免本轮样片的严重洋红；补充 Nikon Z5II/Z50II、Fujifilm GFX100RF、OM-3 精确机型矩阵。
  Corrects the R6 III ColorData layout and matrix, and adds exact-model matrices for Z5II/Z50II, GFX100RF and OM-3.
- 修复 X-Trans 并行去马赛克的数据竞争，保留多线程；修复 OM-1 白平衡模式切换时改变色矩阵的问题。
  Removes the X-Trans parallel demosaic race without globally disabling threads, and keeps OM-1 color-matrix selection independent of white-balance mode.
- 修复 Sony a7R VI 超大默认内嵌预览的曝光匹配，以及 Hasselblad X2D II 100C 的活动区域裁切。
  Uses a bounded alternative embedded preview for a7R VI metering and corrects X2D II active-area cropping.
- RAW 解包报告损坏时不再继续导出；Nikon Z50II HE* 正确返回不支持，不输出横纹或绿块。
  Rejects decoder corruption and unsupported Z50II HE* instead of exporting damaged pixels.
- Windows 提供从 Mac 发起的 SSH 编译和回传入口；iOS 自动构建带补丁的三架构 XCFramework。修复 Windows PowerShell 5.1 下的 ExifTool 打包检查。
  Adds remote Windows builds, reproducible iOS frameworks and a Windows PowerShell 5.1 ExifTool packaging fix.

本版不包含仍在开发中的批量导出、编辑记忆和新增 RAW 降噪功能。Windows native 库随本次源码重新构建，不复用 v0.4.0 的历史交接包。

In-progress batch export, edit persistence and new RAW noise reduction are excluded. Windows native libraries are rebuilt from this release, not reused from the v0.4.0 handoff.

## 验证边界 / Validation Limits

修复阶段的 Mac 26 款公开样片中，24 款通过 RAW、白平衡及导出检查；Nikon Z6III/Z50II 的 HE* 样片仍不支持。Windows 和 iOS 分别完成 9 款样片 RAW/白平衡验证，iOS 模拟器另有 3 款 Metal 检查。具体样片、修复证据与独立发布构建验证见[兼容性记录](https://github.com/dancancer/RawLab/blob/v0.4.1/docs/verification-raw-compatibility-2026-10-09.md)。不能把单个样片推广到同型号所有压缩、位深、连拍或像素位移模式。

During fix validation, 24 of 26 public Mac camera samples passed; the two Nikon HE* samples remain unsupported. Windows and iOS each passed RAW/white-balance checks for nine cameras; three iOS simulator samples also passed Metal tests. See the [compatibility report](https://github.com/dancancer/RawLab/blob/v0.4.1/docs/verification-raw-compatibility-2026-10-09.md) for exact fixtures and isolated release-build evidence. A passing sample does not certify every camera mode.

独立发布源码复测：Mac arm64 重跑全部 26 款，仍为 24 通过 / 2 HE* 不支持；Intel/Rosetta 4 款通过；两种 Mac 架构各 8 项 CTest 通过。Windows 重新编译后 9 款 RAW/WB 和 3 项 CPU CTest 通过。Android 36 项主机单元测试、正式签名与 16 KB 对齐检查通过。iOS 重新构建后 4 款 RAW/WB、3 款 Metal、应用导出和 HE* 拒绝检查通过。

The isolated release tree was retested: Mac arm64 reproduced 24 passes and two HE* rejections across all 26 samples; four Intel/Rosetta samples and eight CTests on each Mac architecture passed. Rebuilt Windows passed nine RAW/WB samples and three CPU CTests. Android passed 36 host unit tests, signing and 16 KB alignment checks. Rebuilt iOS passed four RAW/WB samples, three Metal samples, app export and HE* rejection checks.

Windows 编译 VM 没有真实 Direct3D 11 显卡；未把 CPU/WARP 回退算作 GPU 验证。iOS 尚未完成物理设备安装、内存和温控验证；模拟器 Metal 不等于真机 GPU 验收。Mac Intel 使用 Rosetta，不是原生 Intel 硬件。X-Trans 修复增加每像素 8 字节临时内存，40 MP 约增加 304 MiB，移动设备仍可能受到内存限制。

The Windows build VM lacks a hardware Direct3D 11 adapter. Physical iOS installation, memory and thermal testing remain outstanding; simulator Metal is not device certification. Intel Mac validation uses Rosetta, not native Intel hardware. X-Trans adds eight temporary bytes per pixel, about 304 MiB for 40 MP, so mobile memory remains a constraint.
