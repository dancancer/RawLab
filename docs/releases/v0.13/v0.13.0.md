# RawLab 0.13.0

Version `0.13.0`, build `25`.

## New and improved

- **Tone Curve Free Endpoint X & Canvas Isolation (all four clients + CPU/Metal/GLES/D3D11)**: Endpoints can now move horizontally inward along `X` (`x0` / `x_{n-1}`) across both the master curve and `R/G/B` channel curves, with inputs outside the endpoint range clamping flat to the endpoint's `Y` value. Point and parametric curve canvases are isolated, and point deletion interactions are streamlined (including preserving double-click deletion across `ReleaseMouseCapture` on Windows).
- **Sony SSH Access Auth & α7M5 Dual-Slot Import (iOS & Android)**: Added Sony SSH Access Auth tunnel (with localhost forwarding), connection UI, and dual-slot camera import on iOS and Android, backed by consolidated Sony PTP/IP bounds, live-view tests, and focus state management in `lutools`.
- **Opt-In Diagnostic Logging & Cloud Upload**: Added opt-in diagnostic session recording with full prefix-path redaction, ZIP export, and Aliyun SLS cloud upload.
- **Desktop UI, HDR & Agent Hot-Reload Improvements**: Fixed macOS and Windows layout, HDR airspace, HUD, and v2 panel issues; aligned Windows HDR inline display and float rounding; unified `gui_store` synchronization/locking in `sony2fuji` CLI; enabled Windows `sync_photo_edit` hot-reload; and exposed public RGBA16 diagnostic C APIs.
- **Android Inspection Overlay Refinements**: Fixed inspection overlay overlap and cache loops, kept the inspection HUD unfaded during drags, measured stack height accurately, and polished inspection pill UX.
- **v0.13 Architecture Deepening (W-A ~ W-F)**: Merged the Apple `RawLabKit` dual-track and aligned 24 `v0.13` spec fields across all four clients; unified core `CanonicalEditState`, core HDR→SDR `RGBA8`/`BGRA8` encoding, and the 3-way Android JNI split; sunk `InspectionSuite` geometry/overlays into `lutools` and guidance into `rawlab_mcp`; extracted `ViewportRenderEngine`, fast GPU/pyramid C ABI, and unified Android/Windows document/persistence coordinators; and consolidated `PinnedSourceFile`, `AtomicOutputTransaction`, and Apple ProRAW/display preview ABI.

## Compatibility and known limits

- Downgrading is not supported for edits using `0.13.0` features: curves with non-`0`/`1` endpoint `X` coordinates require SDR edit JSON schema `18` or HDR schema `19` (`rawlab_hdr` processing version `10`), which `0.12.x` and earlier reject by version instead of misreading. Writers choose the lowest schema version required by the edit.
- AI denoising requires a hardware GPU (Apple Silicon Core ML on macOS, DirectML/D3D12 on Windows) and the licensed DualDn/Restormer model package; there is no CPU neural-inference fallback. Intel macOS builds exclude AI denoising.
- Mac installers use the fixed self-signed certificate and Sparkle EdDSA signing (not notarized; first launch requires explicit approval via **System Settings → Privacy & Security → Open Anyway**). Windows automatic updates require the current-user Setup installer (`0.9.0` or later) and P-256 signed `windows-stable.json` (minimum version `0.9.0`; SmartScreen may require **More info → Run anyway**).
- The unsigned iOS IPA requires valid user signing and provisioning before installation and is not an App Store or TestFlight package.
- For camera import, HDR, ProRAW, X3F, and minimum-OS device coverage boundaries, see the [0.12.0 release notes](../v0.12/v0.12.0.md#compatibility-and-known-limits), [0.11.0 release notes](../v0.11/v0.11.0.md#compatibility-and-known-limits), and `BUILD-PROVENANCE.json` attached to the release.
