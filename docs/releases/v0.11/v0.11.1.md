# RawLab 0.11.1

Version `0.11.1`, build `21`.

This is an Android hotfix for the cold-start crash in 0.11.0. The macOS,
Windows and iOS packages remain at 0.11.0 and are not republished here.

## Fixed

- Android release startup no longer aborts when R8 processes the Aliyun RUM
  SDK. Its `libproducer.so` resolves `LogProducerHttpTool` and
  `LogHttpResponse` by JNI class name; the minified release DEX now keeps both
  classes and their members. The release packaging check rejects an APK that
  omits either class.

## Upgrade and compatibility

- The Android APK uses the existing 0.11.0 release signing identity and can
  update 0.11.0 in place. Edits and the 0.11.0 data format are unchanged.
- Downgrading to 0.10.x or earlier remains unsupported; see the
  [0.11.0 compatibility notes](v0.11.0.md#compatibility-and-known-limits).

## Downloads

Download `RawLab-Android-0.11.1.apk` from the
[GitHub Release](https://github.com/dancancer/RawLab/releases/tag/v0.11.1).
The release includes SHA-256 checksums, build provenance, and the current
desktop update metadata. macOS appcasts and `windows-stable.json` are carried
forward unchanged from 0.11.0 so desktop update checks continue to resolve;
they still point to the 0.11.0 desktop packages.

## Verification

The release provenance records the exact source revision, signed APK digest,
DEX class check, Android 15 emulator cold-start result, and checks not run on
physical Android devices. The complete 0.11.0 Android feature and compatibility
notes remain in the [0.11.0 release notes](v0.11.0.md).
