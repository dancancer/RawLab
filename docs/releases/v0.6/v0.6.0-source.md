# Rebuilding RawLab v0.6.0

`RawLab-0.6.0-source.tar.gz` contains the `v0.6.0` project tree with RAW fixtures,
historical client binaries, local review screenshots and experimental reference/
comparison photographs omitted, plus pinned native dependency
archives under `dependency-sources/`. `BUILD-PROVENANCE.json` records the tag,
built release tree and dependency hashes. GitHub's automatic source archives
do not include the separate pinned dependency archives.

Original project code is [GPLv3 only](../../../LICENSE). Dependency and historical
terms remain in [the licensing notice](../../reference/licensing.md). No private photos,
signing keys, credentials or model weights are supplied. Client resources include
the shared recipe catalog, fourteen LUTs and fourteen style artworks.

## macOS

Install Apple Command Line Tools, CMake, pkg-config and make, then build both
architectures using the pinned sources:

```sh
mkdir -p build/macos15-deps/sources
cp dependency-sources/* build/macos15-deps/sources/
for arch in arm64 x86_64; do
    RAWLAB_ARCH="$arch" MACOSX_DEPLOYMENT_TARGET=15.0 bash RawLabMac/build-dependencies.sh
    RAWLAB_ARCH="$arch" MACOSX_DEPLOYMENT_TARGET=15.0 \
      PKG_CONFIG_PATH="$PWD/build/macos15-deps/$arch/install/lib/pkgconfig" \
      RAWLAB_BUILD_DIR="$PWD/lutools/build-macos15-$arch" \
      RAWLAB_APP_PATH="$PWD/build/macos15-$arch/RawLab Mac.app" \
      bash RawLabMac/build.sh
done
```

The scripts verify fixed archive hashes and apply the shared LibRaw and wavelib
patches. OpenCV 4.12.0 includes matching `opencv_contrib` ximgproc sources.

## iOS

Use full Xcode, CMake and pkg-config:

```sh
mkdir -p lutools/build-ios-libraw/0.22.2/sources
cp dependency-sources/LibRaw-0.22.2.tar.gz \
   dependency-sources/LibRaw-cmake-eb98e43.tar.gz \
   dependency-sources/opencv-4.12.0.tar.gz \
   dependency-sources/opencv_contrib-4.12.0.tar.gz \
   lutools/build-ios-libraw/0.22.2/sources/
cp dependency-sources/wavelib-7f61bf592f3c470b2a7d8199431fde821d7253ac.tar.gz \
   lutools/build-ios-libraw/0.22.2/sources/wavelib-7f61bf5.tar.gz
IOS_DEPLOYMENT_TARGET=18.0 bash lutools/build.sh ios
xcodebuild -project RawLab/RawLab.xcodeproj -scheme RawLab \
  -configuration Release -destination 'generic/platform=iOS' \
  -derivedDataPath build/ios-release CODE_SIGNING_ALLOWED=NO \
  CODE_SIGNING_REQUIRED=NO build
```

The framework builds device arm64 and simulator arm64/x86_64. To assemble an
unsigned IPA, place `RawLab.app` in `Payload/` and ZIP the complete directory.
Installation requires your own certificate and provisioning profile.

## Android and Windows

- Follow the [Android guide](../../../RawLabAndroid/README.md) for SDK/NDK/Gradle
  requirements. `scripts/build-release.sh` accepts external signing paths; the
  original signing identity is not supplied. Both native ABIs are rebuilt from
  the pinned sources, including shared HSL and GLES filters.
- On a prepared Windows x64 host, run `RawLabWindows/build.ps1 -SelfContained`.
  It builds the shared native core and D3D11 shaders, downloads hash-verified
  dependencies and includes ExifTool's Perl source/notices. See the
  [Windows guide](../../../RawLabWindows/README.md).

Rename `RawLab-Windows.zip` to `RawLab-Windows-0.6.0-win-x64.zip` and
`RawLab-Android-release.apk` to `RawLab-Android-0.6.0.apk` before publication.
Versioned filenames must match installation links and platform update checks.

`LibRaw-0.22.2-patched-source.tar.gz` separately supplies the actual patched
LibRaw tree, fixed CMake wrapper, calibration data and build scripts. The full
project archive contains the clients, shared GPU/core sources and the remaining
pinned native dependency archives. External RAW test fixtures are optional;
set `RAWLAB_TEST_RAW` or the documented platform fixture option to run real-RAW
checks. Never overwrite an original RAW.
