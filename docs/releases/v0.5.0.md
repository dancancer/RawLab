# RawLab v0.5.0

This release publishes the current `development` feature set as version `0.5.0`,
build `8`. All client executables and native processing libraries are rebuilt
from the release source. The PR against `main` remains open for review; the
release tag identifies the same verified source commit.

## What's New

- Linear-light wavelet denoising on Windows, macOS, Android and iOS, with luma,
  chroma and coarse-chroma controls, plus Detail and Clean presets.
- Per-photo local edit memory and resumable batch RAW export. Jobs freeze the
  source settings, denoising and look, preserve originals and target edit
  records, and support cancellation, interruption recovery and failed-item retry.
- Photo information overlays and original-size or custom long-edge exports on
  all four clients. Presets include 2048, 3000 and 4096 pixels; sizing preserves
  aspect ratio and never enlarges smaller images.
- Desktop file-tree actions to reveal files or apply current settings to
  confirmed photos or a folder's immediate RAW children. This is separate from
  non-destructive batch export and does not include subfolders.
- macOS vignette and deterministic grain controls, with source-resolution Metal
  effects. Metal accelerates wavelet filtering and display-chroma guided
  filtering; Auto retains CPU fallback and Force reports GPU failures.
- English project README with a linked Chinese translation, a separate
  [changelog](../../CHANGELOG.md), and standalone installation documentation.
- Original project code is distributed under `GPL-3.0-only`. Third-party
  licenses and the historical MIT notice remain included.

The LibRaw 0.22.2 compatibility patches from v0.4.1 remain in all four clients.
This is not a complete GPU RAW pipeline, a Lightroom-compatible renderer or a
pixel-exact Fujifilm in-camera JPEG implementation.

## Signing and Known Limits

- Android retains the release signing identity for upgrades from earlier
  release-signed versions. It cannot replace differently signed debug packages.
- Windows is unsigned. Its build VM does not have a hardware Direct3D 11
  adapter; CPU or WARP results are not hardware-GPU validation.
- macOS apps are ad-hoc signed and not notarized. Intel validation uses Rosetta;
  native Intel and physical macOS 15 validation remain outstanding.
- **The unsigned iOS IPA cannot be installed directly.** Re-sign the app and
  embedded framework with a valid certificate and provisioning profile. It is
  not an App Store or TestFlight distribution. Simulator checks do not certify
  physical-device installation, GPU behavior, peak memory or thermals.
- Nikon Z6III/Z50II HE* samples remain unsupported and are rejected rather than
  exported as damaged images. Passing a camera sample does not certify every
  compression, bit depth or shooting mode.
- X-Trans demosaic retains the temporary eight-byte-per-pixel input copy added
  in v0.4.1, about 304 MiB for 40 MP; mobile memory remains a constraint.

Personal RAW files, private signing material and build-machine credentials are
not included in the source or binary archives.
