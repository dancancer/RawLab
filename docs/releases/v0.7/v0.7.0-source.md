# Rebuilding RawLab v0.7.0

Use the exact `v0.7.0` tag or the corresponding project source archive in
[the release](https://github.com/dancancer/RawLab/releases/tag/v0.7.0).
Version 0.7.0/build11 includes the accepted five-feature baseline `3f252a1` and
verified Sony memory fix `627d45e7a8dddb0424203afba08c46a0515113be`.
The final packages were built from source `2dac9d90558a8e899066d3cb01508767d3e4eeed`;
later release documentation does not change native/client processing inputs.
`BUILD-PROVENANCE.json` records final tag/tree and package identities.

`RawLab-0.7.0-source.tar.gz` contains the tag's project tree plus pinned
dependency archives. `LibRaw-0.22.2-patched-source.tar.gz` provides the matching
patched dependency and CMake wrapper. Original project code and dependency
terms are described in [licensing](../../reference/licensing.md).

## Native Dependencies

Keep the actual pinned dependency sources and matching patches:

- LibRaw 0.22.2 and its shared CMake wrapper and compatibility patches.
- Adobe DNG SDK 1.7.1 Build 2724, including JPEG XL, Brotli, Highway and skcms;
  fixed archive and SHA-256 are in `lutools/cmake/dng-sdk.cmake`.
- libtiff 4.7.1, using `lutools/cmake/tiff-dependencies.cmake` and the Mac
  `RawLabMac/build-tiff-dependency.sh` entry point.
- Lensfun 0.3.4, the vendored DB1 snapshot and platform dependencies pinned in
  `lutools/cmake/lens-dependencies.json`. Use the matching GLib and PCRE2
  sources and the documented platform adjustments.
- OpenCV 4.12.0 with matching opencv_contrib, and patched wavelib.

See [Lens platform notes](../../reference/platforms/lens-correction.md) for the pinned
dependency and DB licensing details. An earlier v0.6.0 dependency archive
does not contain all newly required sources.

## macOS

Use Apple Command Line Tools, CMake, pkg-config and an arm64 GLib installation.
The candidate retains the published macOS 15 support target. Use an explicit
15.0 target, fresh CMake directories and a matching dependency prefix for
Apple Silicon. This candidate build and minimum-OS/package closure passed on host macOS
27.0.1; actual macOS15 runtime remains unverified. The earlier final
composition test build used target 26.0:

```sh
RAWLAB_ARCH=arm64 MACOSX_DEPLOYMENT_TARGET=15.0 \
  bash RawLabMac/build-dependencies.sh
RAWLAB_ARCH=arm64 MACOSX_DEPLOYMENT_TARGET=15.0 \
  RAWLAB_DEPENDENCY_PREFIX="$PWD/build/macos15-deps/arm64/install" \
  PKG_CONFIG_PATH="$PWD/build/macos15-deps/arm64/install/lib/pkgconfig" \
  RAWLAB_BUILD_DIR="$PWD/lutools/build-release-v070-arm64" \
  RAWLAB_APP_PATH="$PWD/build/release-v070/RawLab Mac.app" \
  bash RawLabMac/build.sh
```

The scripts fetch or reuse hash-verified source archives, apply the shared
patches and include runtime dependencies, six-language resources, Lens DB
and licenses. Use a fresh CMake directory with the matching dependency
prefix; a stale cache from another worktree can select incompatible LibRaw
or SDK binaries. The build performs local ad-hoc signing. It does not
notarize or produce Developer ID distribution.

## iOS

Use full Xcode and the native framework build scripts:

```sh
IOS_DEPLOYMENT_TARGET=18.0 bash lutools/build.sh ios
xcodebuild -project RawLab/RawLab.xcodeproj -scheme RawLab \
  -configuration Release -destination 'generic/platform=iOS' \
  -derivedDataPath build/ios-release-v070 CODE_SIGNING_ALLOWED=NO \
  CODE_SIGNING_REQUIRED=NO build
```

The framework comprises device arm64 and simulator arm64/x86_64 slices.
An unsigned IPA can be assembled from the app in `Payload/`; installation
requires valid user signing and provisioning. No valid Apple identity/profile
is present on the release host, so no installable iOS 0.7 package is published. Build success does not
establish physical-device memory, GPU or thermal behavior.

## Android and Windows

- Follow [the Android guide](../../../RawLabAndroid/README.md) for SDK, NDK and
  Gradle requirements. From `RawLabAndroid/`, `./gradlew :app:assembleRelease`
  produces the local unsigned release APK without using an external signing
  key. `scripts/build-release.sh` uses an existing external release keystore and
  password file; no signing key is included in source. The published APK uses
  the same certificate as v0.6.0.
- Follow [the Windows guide](../../../RawLabWindows/README.md) on a prepared
  Windows x64 host. `RawLabWindows/build.ps1 -SelfContained` builds the
  native core and managed app and includes runtime libraries and notices.
  If host policy blocks the script, record that limitation and use the
  equivalent existing CMake/dotnet entry points without changing policy.

External RAW fixtures are optional and are not distributed. Set
`RAWLAB_TEST_RAW` or the documented platform fixture option for focused
checks. Never overwrite an original RAW. Preserve the exact project,
patched dependency source and source provenance when redistributing
release binaries.
