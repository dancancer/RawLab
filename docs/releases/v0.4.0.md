# RawLab v0.4.0

本次发布包含 Windows 日期标识独立运行包、macOS 15 双架构应用和 Android 正式签名 APK。iOS 暂不重发，继续使用 [v0.2 未签名包](https://github.com/dancancer/RawLab/releases/tag/v0.2)，其中不包含后续源码更新。

## 更新

- Windows 选片先显示相机内嵌预览，再补齐 RAW 显影；双击立即放大并后台补齐原尺寸细节。重复缩放复用精确图像缓存，平移复用图像图层，支持远程桌面环境下的 WPF 硬件绘制。
- Windows 启用多核 RAW 处理，关闭对比或裁切提示时避免不必要的处理。导出仍须等待精确结果，并独立生成全分辨率成片。
- Mac 和 Android 增加持久化自定义外观库，支持 CUBE/RLOOK 的批量导入、重命名和删除。导入文件保存为托管副本，重启或删除外部原文件不影响外观；批量部分失败保留成功项，显示失败文件，选中最后成功项。
- Windows 的外观导入支持多选，但仍使用会话内的外部文件引用，不包含 Mac/Android 的持久化托管库和逐文件导入报告。
- Fuji F-Log/F-Log2/F-Log2C CUBE 可按声明的色彩约定直接使用；技术 Log 输出会解码为显示图像。共享核心增加对应 Metal、GLES 和 Direct3D 11 路径，Auto 在后端失败时回退 CPU。
- Mac 和 Android 版本更新为 `0.4.0`，构建号为 `5`。

## 验证范围

本轮从当前源码重新构建并验证：

- Mac arm64、x86_64 的 CTest 各 13/13 通过，包含真实 Sony/DJI RAW、白平衡、缓存、Metal/CUBE/DCP 和图像统计回归；两种架构的实际应用均通过 Sony/DJI 预览、原尺寸导出及缺失输入检查。
- Mac 外观库和编辑模型回归通过，覆盖批量部分成功、全部失败、取消、重启恢复、损坏索引和原文件保护。新增竖拍样片检查时发现旧 RAW 测试直接比较旋转前后的像素，已修正参考坐标映射，未修改显影代码或放宽误差阈值。
- LUT 准备工具运行 97 项测试：96 项通过，1 项因未提供可选外部 Canon DCP 而跳过；原生 DCP 对照已启用。
- Android Release 单元测试 33/33、Lint、正式签名和两个 ABI 共 8 个原生库的 16 KB 对齐检查通过。API 35 ARM64 模拟器对实际正式签名 APK 执行 35 项仪器测试，包含相册、编辑器、外观库、批量导入、真实 RAW、Fuji GLES 一致性与导出 EXIF。
- Android 已核对与已发布 v0.3.0 的证书一致，并完成不卸载的覆盖安装，版本从 `0.3.0/4` 更新为 `0.4.0/5`。4 项依赖 Debug 专用测试 Activity 的组件测试未在正式 APK 上运行；模拟器 GLES 路径不等于物理设备性能测试。
- Mac 包的架构、最低系统版本、依赖闭包、签名及 ZIP 完整性通过；应用安装包未包含私人 RAW、Adobe profiles、派生测试外观或签名密钥。

Windows 运行验证来自交接记录：119 项 Windows 检查、11 项 native 检查通过，38 组 Sony/DJI 输出像素哈希一致。本次在 Mac 上另外核验了分片和完整包 SHA-256、ZIP CRC、运行库和许可清单，未在本机执行 Windows 二进制。

性能记录中的 43 ms 内嵌首帧、约 4 ms 重复原尺寸缩放和 31.5 ms 平均合成间隔来自特定 Windows 机器和约 32 Hz 的远程桌面，本地文件缓存未清空，不代表冷盘、网络盘或固定帧率承诺。详见 [Windows 性能记录](https://github.com/dancancer/RawLab/blob/v0.4.0/RawLabWindows/performance.md)。

## 边界

- RAW 解码、去马赛克和文件编码仍在 CPU，并非全流程 GPU 显影；原生 DCP/RLOOK 的 GPU 路径限 Metal，Android/Windows 使用 CPU 回退。
- 可解析、可导入及 CPU/GPU 一致性，不代表完成所有相机的色彩标定或完整复刻 Fuji/Adobe/Lightroom 的输出。DCP 不替换目标 RAW 的传感器校准或白平衡，源 XMP 尚不能直接执行。
- 自定义外观导入接受准备好的 CUBE/RLOOK，不直接执行源 DCP/XMP；制备方法见 [LUT 准备文档](https://github.com/dancancer/RawLab/blob/v0.4.0/lutools/docs/lut-preparation.md)。
- 私人 RAW 样片、Adobe profiles 和派生测试外观不随应用分发；Windows 随附的 ExifTool 官方发行目录保留其自带测试资源。
