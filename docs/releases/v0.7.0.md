# RawLab v0.7.0

Version `0.7.0`, build `11`.
[Release and downloads](https://github.com/dancancer/RawLab/releases/tag/v0.7.0).

## What's New

- Decode supported JPEG XL-compressed DNG data through Adobe DNG SDK 1.7.1.
- Export rendered float32 DNG alongside JPEG and 16-bit PNG. Rendered DNG
  contains processed pixels rather than the original sensor mosaic.
- Apply Lensfun profile-based distortion and lateral chromatic-aberration
  correction, with automatic/manual profile selection and auto-crop.
- Use English, Simplified Chinese, German, French, Japanese and Spanish on
  all four clients. Switching language preserves editing and batch settings.
- Render previews at the current viewport size and reuse denoise analysis;
  FINAL exports retain independent full-quality rendering.

## Fixes

Sony full-resolution CPU export now releases reconstructible intermediate
buffers before wavelet filtering. The dedicated 2.5GB Android AVD completed
original-size JPEG/PNG/DNG and independent FINAL exports; sampled native heap
fell from approximately 2.085GB to 1.692GB. Complete before/after files match
byte-for-byte on CPU and Force GLES. Parameters, cache identities, output
encoding and quality thresholds are unchanged. GPU Auto retains CPU fallback;
Force still requires actual backend success.

## Validation and Limits

[Release verification](../archive/releases/v0.7/0.7.0-release.md) records the rebuilt
packages. [Sony memory verification](https://github.com/dancancer/RawLab/blob/a38ac6065f747cc43ddbee1c8df232c049b288d2/docs/verification-android-sony-dng-memory-2026-10-14.md)
and [the integration tracker](../archive/integration/v0.7/acceptance-index.md) retain existing
tests and independent reviews. Local results are not hosted CI.

GPU acceptance is limited to devices with at least 6GB RAM by user request;
the actual Force GLES device has approximately 12GB. Exactly 6GB was not
tested. The earlier whole-client evidence retains its source/configuration;
the final package rebuild adds no new GUI or hardware-runtime test. Physical
macOS15, Intel Mac, iOS Files cancellation and Windows SaveFileDialog/Explorer
coverage remain pending. Mac packages use ad-hoc signing and Windows binaries
are unsigned. No notarization, App Store or TestFlight distribution is claimed.

## Dependencies and Source

The release includes Adobe DNG SDK/JPEG XL, libtiff 4.7.1, Lensfun 0.3.4/DB1 and
the corresponding GLib/PCRE2/platform dependencies and notices. Original
project code remains GPL-3.0-only; third-party terms and DB attribution are
retained. Personal RAWs, reference photographs, credentials and signing keys
are excluded from corresponding-source packages.
