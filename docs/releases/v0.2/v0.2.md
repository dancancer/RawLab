# RawLab v0.2

胶片强度上限提升至 **200%**，JPEG / 16-bit PNG 导出保留拍摄 EXIF。

## 下载

- `RawLab-Windows-0.2-win-x64.zip`：Windows 10/11 x64 独立运行包，解压后运行 `RawLab.exe`。
  包含 .NET 8、Visual C++ 运行库、LUT 和 ExifTool；请保留完整目录。
- `SHA256SUMS.txt`：附件 SHA-256 校验值。
- `LibRaw-0.21.5-source.tar.gz`：Windows 构建所用 LibRaw 源码。

这是统一的 v0.2 发布，源码包含 Windows、Mac、Android 和 iOS 的相应功能。
**本次先提供 Windows 安装包，Mac（Apple Silicon / Intel）、Android 和 iOS 的附件待后续补充。**
其他平台尚未在本次 Windows 构建环境重新验证。

## Windows 更新

- 胶片滑杆和数值输入支持 0–200%，默认和重置值仍为 100%；CPU 和 Direct3D 11 均生效。
- 导出保留可读取的相机、镜头、拍摄时间、快门、光圈、ISO、GPS 等拍摄信息。
- EXIF 方向、尺寸和 sRGB 标记描述实际导出图像，不复制旧缩略图、RAW 布局或 MakerNotes。
- 写入元数据不重新压缩 JPEG、不改变 PNG 的压缩像素数据或 16-bit 精度。
- EXIF 组件随包附带；写入失败时不替换已有目标文件，不修改原始 RAW。

## 验证

- 共享 C++ 核心回归 **7/7** 通过。

- 合成样片验证 EXIF、GPS、中文路径、无拍摄信息输入、方向和尺寸；JPEG/PNG 图像数据写入前后完全一致。
