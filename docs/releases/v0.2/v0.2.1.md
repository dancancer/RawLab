# RawLab v0.2.1

本次补丁发布更新 Mac 和 Android，修复大量照片浏览时的位置保持问题。Windows 和 iOS 不重发，继续使用 [v0.2](https://github.com/dancancer/RawLab/releases/tag/v0.2)。

## 更新

- Mac：修复大目录中选中照片后滚动条或照片位置跳变。文件树改用单层原生列表，保留两列缩略图、按需加载和子目录展开/收起。
- Android：选片进入编辑器后再次打开相册，恢复滚动位置和相册筛选。
- Android：手动刷新、后台恢复和 Activity 重建时保留浏览位置；原相册已删除时回退到可用照片。
- 两端版本号为 `0.2.1`，构建号为 `3`；不改变照片处理和导出流程。

## 下载与安装

| 平台 | 附件 | 要求 |
| --- | --- | --- |
| Mac Apple Silicon | `RawLab-Mac-0.2.1-macOS15-arm64.zip` | macOS 15+，M 系列 Mac |
| Mac Intel | `RawLab-Mac-0.2.1-macOS15-x86_64.zip` | macOS 15+，Intel Mac |
| Android | `RawLab-Android-0.2.1.apk` | Android 8.0+，ARM64 / x86_64 |

- Mac 应用采用 ad-hoc 签名，未经过 Apple 公证。最低系统版本及依赖兼容性已做构建检查；尚未在 macOS 15 真机上验证，Intel 版本在 Apple Silicon 上通过 Rosetta 测试。
- Android 使用与 v0.2 相同的正式发布证书，`versionName=0.2.1`、`versionCode=3`，支持覆盖升级旧正式版；不能覆盖不同签名的 debug 版。
- `SHA256SUMS.txt` 提供附件校验值。两个 LibRaw 源码归档分别对应 Mac 官方发行源码和 Android 使用的源码；许可证保留在应用内。

## 验证

- Mac：arm64 和 x86_64 核心测试各 8/8；两种架构的实际应用均通过 Sony RAW / DJI DNG 预览及 JPEG / 16-bit PNG 导出检查。
- Mac：单目录 1001 张、多目录 3003 张和嵌套目录的选片回归测试，在 arm64 及 Rosetta/x86_64 下通过，覆盖 200/240/300 点侧栏宽度。
- Mac：应用及内嵌依赖的架构、macOS 15 最低系统版本、签名和依赖完整性检查通过。
- Android：Release 单元测试 12/12，Release Lint 通过；实际正式签名 APK 在 Android 15 ARM64 模拟器上通过全部 16 项设备测试，包含 6 项新增相册回归测试及真实 Sony RAW 渲染/导出验证。
- Android：从已发布的 v0.2 APK 覆盖升级到 v0.2.1 成功；发布证书一致，两个 ABI 的 16 KB 对齐检查通过。
- 构建源码对应 `v0.2.1` 标签；测试 RAW 样片不包含在发布包或 Git 提交中。
