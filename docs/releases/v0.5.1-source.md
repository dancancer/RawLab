# Rebuilding RawLab v0.5.1

`RawLab-0.5.1-source.tar.gz` contains the exact `v0.5.1` project tree and pinned
native dependency archives under `dependency-sources/`. `BUILD-PROVENANCE.json`
identifies the tagged commit, built release tree and dependency hashes. GitHub's
automatic source archives contain only the project tree.

Original project code remains [GPLv3 only](../../LICENSE); dependency and
historical terms remain in [the licensing notice](../licensing.md). No signing
keys, credentials, personal RAW fixtures or historical client binaries are supplied.

## macOS

Install Apple Command Line Tools, CMake, pkg-config and make, then use the pinned
archives and build each architecture:

```sh
mkdir -p build/macos15-deps/sources
cp dependency-sources/* build/macos15-deps/sources/
for arch in arm64 x86_64; do
    RAWLAB_ARCH="$arch" MACOSX_DEPLOYMENT_TARGET=15.0 bash RawLabMac/build-dependencies.sh
    RAWLAB_ARCH="$arch" MACOSX_DEPLOYMENT_TARGET=15.0 \
      PKG_CONFIG_PATH="$PWD/build/macos15-deps/$arch/install/lib/pkgconfig" \
      RAWLAB_BUILD_DIR="$PWD/lutools/build-macos15-$arch" \
      RAWLAB_APP_PATH="$PWD/build/macos15-$arch/RawLab Mac.app" \
      bash RawLabMac/build.sh
done
```

The scripts verify fixed archive hashes and apply the shared LibRaw and wavelib
patches. OpenCV 4.12.0 includes the matching `opencv_contrib` ximgproc source.
Metal filters are compiled from the shared core in this tagged tree.

## iOS

Use full Xcode, CMake and pkg-config:

```sh
mkdir -p lutools/build-ios-libraw/0.22.2/sources
cp dependency-sources/LibRaw-0.22.2.tar.gz \
   dependency-sources/LibRaw-cmake-eb98e43.tar.gz \
   dependency-sources/opencv-4.12.0.tar.gz \
   dependency-sources/opencv_contrib-4.12.0.tar.gz \
   lutools/build-ios-libraw/0.22.2/sources/
cp dependency-sources/wavelib-7f61bf592f3c470b2a7d8199431fde821d7253ac.tar.gz \
   lutools/build-ios-libraw/0.22.2/sources/wavelib-7f61bf5.tar.gz
bash lutools/build.sh ios
xcodebuild -project RawLab/RawLab.xcodeproj -scheme RawLab \
  -configuration Release -sdk iphoneos -destination 'generic/platform=iOS' \
  -derivedDataPath build/ios-release CODE_SIGNING_ALLOWED=NO build
```

The framework builds device arm64 and simulator arm64/x86_64 with wavelet and
display-chroma support. Distribution requires your own certificate/profile.

## Android and Windows

- Follow the [Android guide](../../RawLabAndroid/README.md) for SDK/NDK/Gradle
  requirements. `scripts/build-release.sh` uses external release signing paths;
  the original signing identity is not supplied. Native dependencies and GLES
  filters are built for ARM64 and x86_64 from the pinned sources.
- On a prepared Windows x64 host, run `RawLabWindows/build.ps1 -SelfContained`.
  It builds the shared native core and D3D11 shaders from this tree, downloads
  hash-verified dependencies and includes ExifTool's Perl source/notices.
  See the [Windows guide](../../RawLabWindows/README.md).

Rename `RawLab-Windows.zip` to `RawLab-Windows-0.5.1-win-x64.zip` and
`RawLab-Android-release.apk` to `RawLab-Android-0.5.1.apk` before publication.
Versioned asset names must match installation links and platform update checks.

`LibRaw-0.22.2-patched-source.tar.gz` separately contains the actual patched
LibRaw tree, fixed LibRaw-cmake wrapper, calibration data and build scripts.
The complete project archive supplies the clients, shared GPU/core source and
the remaining pinned native dependency archives.
