# RawLab 0.9.3

Version `0.9.3`, build `18`.

## New and improved

- macOS, iOS, Android and Windows can enter HDR editing for supported camera RAW
  and Apple ProRAW files. RAW files open in SDR by default. The editor keeps
  separate HDR and SDR adjustments and restores the saved mode when reopened.
  HDR tools include basic adjustments, geometry, luminance monitoring, HDR/SDR
  preview, and JPEG export with a gain map or an explicit SDR result.
- ProRAW JPEG export processes blocks from the complete original and preserves
  readable capture metadata. Presets and synchronization respect the target
  mode. Batch export freezes each target's settings and preserves completed
  outputs during retry.
- The iOS build uses the iOS 27.1 SDK for iPhone Duo and keeps the iOS 18
  deployment target. The editor keeps its horizontal tools clear of the native
  vertical navigation controls.

## Fixes

- iPad's Files action opens the document picker for photos and LUTs.
- Android master recipes keep the camera white balance and apply the remaining
  effects when the calibrated as-shot white balance is unavailable.
- On Windows, a missing original in an older started ProRAW batch is reported
  by row, and available targets continue exporting. Switching to Save SDR JPEG
  makes compatible rows selectable again while preserving file and decode errors.
- Interrupted SDR JPEG encoding releases its output buffer safely. macOS and
  iOS validate the saved ProRAW decoder version before restoring HDR editing or
  processing an HDR batch target.

## Compatibility and known limits

- Camera RAW HDR admission depends on the source's actual linear decode path.
  See the [camera RAW scope](../../design/hdr-photos/camera-raw.md).
- Apple ProRAW uses Core Image on macOS/iOS and the Adobe DNG SDK on
  Android/Windows. The same photo can render differently across those two
  decoder families. See [ProRAW support and export limits](../../design/hdr-photos/proraw.md).
- Mac HDR editing requires macOS 15+. Full-size ProRAW HDR and SDR JPEG export
  on iOS is enabled on iPhone 14 Pro Max with iOS 27, subject to memory and
  available disk space. The full-frame iOS PNG/DNG path retains its 12 MP limit.
- HDR display depends on system and screen support. Android HDR presentation
  requires API 34+ and a compatible display and window. Windows uses FP16/scRGB
  where supported. Physical HDR brightness and device performance coverage are
  tracked separately from model, build, simulator and virtual-machine results.
- See the [0.9.2 compatibility notes](v0.9.2.md#compatibility-and-known-limits)
  for X3F and GPU AI denoising limits. Mac installers use the fixed self-signed
  certificate and Sparkle EdDSA. Windows automatic updates use the signed
  descriptor and require the current-user Setup. The unsigned iOS IPA requires
  valid user signing and provisioning.
