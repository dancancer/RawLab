# RawLab v0.9.0

Version `0.9.0`, build `15`. Based on `development` at
`b118e217d1ea6bb1f84a146d9d0b21ee3d8d1cc0`, compared with the published `v0.8.2`
tag. This release reorganizes the editor on every client, adds Lightroom-style
copy and paste, presets, new color and tone tools, photo collections, desktop AI
denoising and automatic desktop updates.

## Changes

- **Reorganized editor.** macOS, iOS, Android and Windows share six adjustment
  groups with change markers and per-group reset, single-line numeric inputs,
  side-by-side and split comparison, and press-and-hold to view the photo
  before adjustments. iOS and Android add a tap for a clean photo preview;
  Android adds and iOS upgrades to a 256-bin RGB histogram.
- **Copy, paste and history.** Copy a photo's adjustments, choose the items to
  paste onto other photos, and undo or redo within the editing session.
- **User presets.** Save named adjustment presets, separate from built-in
  looks and imported LUT/DCP profiles.
- **New adjustments.** Black point, white point and vibrance; shadow, midtone
  and highlight color grading; a multi-point tone curve that keeps the previous
  S-curve control; clarity and dehaze in both directions. Agent recipes and
  exports support all of them.
- **HSL color picking.** Pick a color on the photo and drag to adjust the
  matching HSL range. The target mode stays active when the adjustment panel is
  collapsed, with an on-canvas indicator and exit control.
- **Photo collections.** Sync adjustments across photos, fine-tune one photo,
  and export each photo with its own frozen settings after confirmation.
- **Processing version 2.** New edits use VNG demosaic for ordinary Bayer RAW
  files and an updated denoiser. Existing edits keep processing version 1.
  macOS and Windows offer a processing-version choice.
- **Desktop AI denoising.** macOS on Apple Silicon and Windows x64 with a
  hardware DirectML GPU can denoise RAW files with the bundled DualDn and
  Restormer models. The first calculation runs at full resolution; exposure and
  look changes reuse the cached result.
- **Automatic desktop updates.** macOS and Windows check, download, verify and
  install updates from GitHub Releases, back up editing data first and offer
  recovery if an installation fails.
- **MCP server.** `tools/mcp` exposes five tools over the existing Agent CLI to
  local MCP clients on macOS and Windows.
- **Large images on mobile.** Android and iOS process and export large JPEG,
  PNG and RAW files at full resolution with bounded temporary memory.

## Upgrade And Compatibility

- **No downgrade.** Android 0.8.2 cannot read the new edit library. Saving
  photos after reverting macOS, iOS or Windows discards the new adjustment
  fields and processing-version markers.
- **HSL rendering.** Active HSL adjustments now keep out-of-range color detail
  after contrast and saturation instead of clamping it. Existing edits that use
  HSL can look different; there is no switch to restore the old behavior.
- **Windows single instance.** Opening another file through Open With, or
  starting a second copy, asks the user to quit the other RawLab instance; the
  new process then exits.
- **First installation from 0.8.2.** Install 0.9.0 manually once; later
  versions update automatically. Windows automatic updates require the
  current-user Setup installation; the ZIP package only supports manual
  updates. The Mac app must be in a location the current user can write to.
- **Signing.** RawLab is free and does not use Apple notarization or Windows
  Authenticode. macOS uses a fixed self-signed certificate plus Sparkle EdDSA;
  Windows trusts only a signed release manifest that binds the package size and
  SHA-256. The first launch may need **System Settings → Privacy & Security →
  Open Anyway** on macOS or **More info → Run anyway** in Windows SmartScreen.
  The Mac signing identity changes from 0.8.2, so macOS may ask for folder
  access again.
- **AI requirements.** Core ML on Apple Silicon with macOS 14 or later, or a
  hardware DirectML/D3D12 GPU on Windows x64. There is no CPU AI mode, and Auto
  does not fall back to CPU neural inference. Intel Macs, iOS and Android do not
  include AI denoising in this release. The models increase download size.
- **Model licenses.** DualDn weights and converted models remain under
  [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/); the
  Restormer generic RGB model keeps its upstream Academic Public License. Both
  are for noncommercial use only and are not relicensed under RawLab's GPL.
  See [licensing](../../reference/licensing.md#dualdn-models-and-desktop-inference-runtimes).
- Platform requirements remain Windows 10/11 x64, macOS 14+, Android 8+ and
  iOS 18+. iOS distribution still requires valid signing and provisioning.
