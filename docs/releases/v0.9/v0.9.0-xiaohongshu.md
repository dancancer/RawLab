# RawLab 0.9.0 更新内容

- 四端编辑界面改版：调整项分成六组，可按组重置，支持直接输入数值、并排和分割对比、按住查看调整前效果。
- 新增调整复制粘贴：可以只粘贴选中的项目到其他照片，并支持撤销和重做。
- 新增用户预设，可以保存常用的调整组合。
- 新增黑场、白场、鲜艳度、三分区颜色分级、多点曲线、清晰度和去朦胧；调整清晰度和去朦胧时预览即时刷新。
- HSL 支持在照片上取色后直接拖动调整。
- 新增照片集合：多张照片同步调整，单张微调，逐张按各自设置导出。
- 新编辑默认使用新的处理版本（新的去马赛克和降噪），旧编辑保持原来的效果。
- Mac（Apple 芯片）和 Windows 新增 AI 降噪，需要显卡支持；模型仅限非商业用途。
- Mac 和 Windows 支持自动更新。从 0.8.2 升级需要手动安装一次，之后可以自动更新。
- 提升 Android 和 iOS 处理、导出大图的稳定性。
- 注意：本版本不支持降级；首次打开时可能需要在系统设置里手动允许运行。
