# RawLab v0.3.0

本次发布更新 Mac 双架构安装包和 Android 正式签名 APK。全部源码改动一并提交；Windows 和 iOS 暂不重发安装包，继续使用 [v0.2](https://github.com/dancancer/RawLab/releases/tag/v0.2)。

## 更新

- Android 相册支持在方形缩略图和原始比例之间切换，可选择每行 1-6 张，默认原始比例、3 列。处理照片方向、缺失尺寸和缩略图加载状态，保留筛选、视图选择和浏览位置。
- 汇总 v0.2.1 后的照片缩放改进：Android 支持双指缩放、平移、双击适应/100% 预览像素切换；对比分割线与双指手势不冲突。Mac 对比视图的缩放行为更一致。
- 新增可选桌面 LUT 准备工具，通过显式色彩约定适配 OCIO 支持的 LUT 格式，并报告转换后的 CUBE 采样误差。不再根据文件名猜测输入色彩空间。
- 支持将 DCP 的矩阵、HSV 表和曲线编译为 `.rlook`，直接计算而非先烘焙整张 RGB CUBE。新增 D65 HueSatMap 支持及原生 Metal 执行；CPU 保留高精度参考路径。
- Mac 自定义外观导入支持 `.cube` 和 `.rlook`。旧版 `.rlook` v1 仍可使用，v2 增加校准表及可选 LookTable。
- Mac 和 Android 版本均为 `0.3.0`，构建号为 `4`。

## 下载与安装

| 平台 | 附件 | 要求 |
| --- | --- | --- |
| Mac Apple Silicon | `RawLab-Mac-0.3.0-macOS15-arm64.zip` | macOS 15+，M 系列 Mac |
| Mac Intel | `RawLab-Mac-0.3.0-macOS15-x86_64.zip` | macOS 15+，Intel Mac |
| Android | `RawLab-Android-0.3.0.apk` | Android 8.0+，ARM64 / x86_64 |

- Mac 采用 ad-hoc 签名，未经过 Apple 公证。主程序及依赖的最低系统版本、签名和架构已检查；尚未在 macOS 15 真机验证，Intel 测试使用 Rosetta。
- Android 沿用正式发布证书，已验证从已发布的 v0.2.1 覆盖升级；不能覆盖不同签名的 debug 版。
- `SHA256SUMS.txt` 提供附件校验值。两个 LibRaw 源码归档分别对应 Mac 官方发行源码与 Android 使用的源码，许可证保留在安装包内。

## 验证

- Mac arm64、x86_64 的核心 CTest 各 10/10 通过，覆盖原有 CUBE、RAW、白平衡、高光及新增原生 DCP/Metal 阶段。
- 两种架构的实际 Mac 应用均通过 Sony RAW、DJI DNG 预览与导出冒烟检查。
- 两种架构均通过真实 RAW 配合 `.rlook` v1/v2 的 CPU/Metal、交互缓存、最终渲染和导出回归；最大像素差为 1 个 8-bit 码值。
- LUT 准备工具 Python 测试 73/73 通过，包含真实 DCP fixture 和原生 C++ 对照。
- Android Release 单元测试 19/19、Lint 和 APK 构建通过；实际正式签名 APK 在 API 35 ARM64 模拟器上通过 23 项相册、编辑器、RAW、存储与 EXIF 测试。
- Android 另有 4 项 Debug 组件测试通过，覆盖缩放手势、对比分割线和缩略图比例回退；Mac 展示状态与缩放逻辑测试通过。
- Android 发布证书与 v0.2.1 相同，两个 ABI 的 8 个原生库通过 16 KB 对齐检查。
- 相册界面已检查手机、平板尺寸、深色模式及大字体；原始 RAW 和测试用的 Adobe profiles 不打入应用安装包。

## 边界

- DCP 适配不替换目标 RAW 的传感器校准或白平衡，不等于 Lightroom 或相机 JPEG 的完整复刻，也不代表所有相机已完成色彩标定。
- 缺失 ToneCurve 的配置必须显式提供曲线；三光源 HueSatMap、HDR/RGB 表和 Adobe 自动黑位等仍不支持。LR 的 XMP 色彩配置尚不能直接执行。
- 自定义外观导入目前限桌面界面。原生 DCP 的 GPU 路径目前限 Metal；其他后端保留 CPU 回退。原有 CUBE 加速不变。
- 本地整理的 Adobe DCP/XMP 和派生测试外观不随本次 release 分发。通过 [LUT 准备文档](https://github.com/dancancer/RawLab/blob/v0.3.0/lutools/docs/lut-preparation.md)使用自己已有的 profiles。
