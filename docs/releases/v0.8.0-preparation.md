## Scope Decisions Before Candidate Freeze

These are conditional release blockers, not grounds to claim an untested platform
has passed or to quietly drop a published compatibility promise.

| Decision | Current evidence and required action |
| --- | --- |
| Simultaneous platforms or staged delivery | Confirm which of macOS, Windows, Android and iOS are in the first 0.8 distribution, and whether iOS is source-only or an installable/store artifact. Keep excluded platforms explicit. |
| macOS minimum and architectures | [README](../../README.md) advertises macOS 15+ and Apple Silicon/Intel, but the current default [build](../../RawLabMac/build.sh) targets 26.0; latest local acceptance is arm64. If retaining that promise, build and run candidates at the promised minimum on Intel and Apple Silicon. macOS 26 hosted CI cannot close it. A changed promise requires an explicit product decision and matching docs/metadata, not just a CI edit. |
| Distribution signing policy | Current macOS validation uses ad-hoc signatures; Windows packages are unsigned. Decide whether those are acceptable distribution forms. Developer ID/notarization, Authenticode or store credentials are not configured by this task. |
| iOS installable delivery | Existing simulator/source/framework results do not prove device signing, provisioning, archive/export or installation. Those are blockers if an installable iOS artifact is in scope. See [iOS readiness](../ios-v08-pr-readiness-2026-10-15.md). |
| RUM packaging | Default/release paths remain vendor-SDK-free. Real RUM upload is not required for that scope. Shipping the vendor SDK instead requires explicit approval and closure of vendor redistribution/license/source obligations; the GPL linking exception does not grant a vendor license. See [licensing](../licensing.md) and [RUM verification](../verification-rum-analytics-2026-10-16.md). |

- [ ] Validate clean-machine install/start, bundled resources/notices/licenses, export metadata and uninstall/profile isolation for each shipped artifact.
- [ ] Complete or explicitly scope the six-language privacy/statistics settings copy and accessibility acceptance.
- [ ] Complete the chosen physical GPU/device/display/long-session gates; retain hardware and source identifiers rather than claiming universal support.
