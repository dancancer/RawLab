# RawLab 更新说明：大师配方与跨端调色

版本：`0.6.0`，构建 `10`。本文汇总 `v0.5.1` 之后的更新；安装包、签名和验证范围见 [v0.6.0 发布说明](v0.6.0.md)。

## 大师配方

macOS、iOS、Android 和 Windows 统一提供 14 个大师配方，使用同一份配方数据与风格图标。

| Jungraphy | 霓虹都市、冷青粉紫 |

- 结合参考素材，对全部 14 个 LUT 做了保留原有风格的有限校准；对通过约束检查的配方补充 HSL 微调，其余保留中性 HSL，不强行改变色彩。
- 应用配方会覆盖曝光、阴影、高光、对比度、饱和度、色调，以及全部 24 项 HSL 设置，并将强度恢复为 100%。
- 强度范围为 0-200%，一起缩放当前六项设置、HSL 和 LUT。应用后仍可手动修改参数，强度会缩放修改后的值，而不是叠加隐藏的预设参数。
- 0% 关闭配方参与的调整；自定义色温、S 曲线、锐化、降噪、暗角和颗粒等独立设置不随配方强度改变。
- 大师配方与普通胶片互斥。切换到普通胶片后，当前可见调整值保留，配方的色调偏移转换为独立白平衡设置。

配方是创意风格参考，不代表摄影师授权、精确复刻原厂胶片，或具备局部补光、光晕等语义效果。图标用于展示风格，不是对应 LUT 的实际渲染样片。

## HSL 与曝光

- 四端新增八色 HSL 混色器：红、橙、黄、绿、青、蓝、紫、洋红，每种颜色可分别调整色相、饱和度和明度。
- HSL 接入预览、最终导出、编辑记录和冻结批量任务，并纳入支持的 Metal、GLES 和 Direct3D 11 调色路径。
- 新增一键自动曝光，按当前照片估算建议 EV；这是亮度估算，不是场景识别或高光恢复保证。
- 新照片默认使用更接近相机内嵌预览的曝光基准，仍可选择场景或传感器基准；旧记录保留原有曝光模式。

## 界面与跨端一致性

- iOS 增加 iPad 支持，根据窗口宽高切换上下布局或右侧调整面板，兼顾横竖屏和窄窗口。
- 大师配方以风格图片、下方名称和更弱一级的说明呈现，不使用外框；macOS 的工具栏图标改为作品集符号。
- iOS、Android 的胶片和大师配方列表直接横向拖动，不显示左右按钮。
- macOS、Windows 在列表超出可用宽度时显示左右按钮；到达边缘时禁用对应方向，列表全部放得下时隐藏按钮。
- iOS、Android、Windows 的当前主调整项与 macOS 对齐，包括基础调色、八色 HSL、降噪、暗角、颗粒、大师配方和整体强度。

## 修复与兼容

- 修正强 HSL 在近灰色区域放大细小色相误差的问题，CPU 与三种 GPU 后端统一平滑减弱分色明度偏移，避免稀疏亮度噪点。

- 修正 iOS 高光方向：正值表示提亮，负值表示压低；同时保持历史记录中原生参数的成片效果不变。
- iOS 对比度、饱和度、阴影、高光和 S 曲线统一显示为 -100 至 100%，锐化扩展至 0-200%。曝光滑块步进为 0.05 EV，色温步进为 10 K。
- 配方色调以目标 RAW 的拍摄白平衡为基准，批量处理逐张解析，不沿用来源照片的相机白平衡；手动设置的色温保留。
- 保存和恢复保留配方选择、手动调整、HSL 与强度，冻结批量任务不重新注入预设默认值。
- 已有 macOS 版本 2 配方记录与冻结任务保留独立 HSL 的原有规则；重新点击配方后才采用新版 HSL 覆盖和整体缩放。
- 修复 macOS 同路径 RAW 文件被替换、但大小和修改时间不变时的显影与白平衡缓存失效问题。

## 验证与发行状态

- 三端补齐后的 14 配方、0/50/100/200% 强度、显式手动设置对照与 CPU/GPU 或自动回退对照已通过；macOS 也完成两种真实 RAW 的对应验收。
- iOS、Android 拖动列表测试，以及 Windows 胶片和配方溢出按钮回归通过。Android 原生回归的 9 个方法均有通过结果，但整组曾被系统清理中断，后续逐项补齐，不计为一次完整的 9/9 运行通过。
- 0.6.0 的正式包与验证结果以[发布验收记录](../archive/releases/v0.6/0.6.0.md)为准。iOS 仍采用未签名分发，需要自行重新签名；尚未验收物理 iPhone/iPad 的安装、内存与温度表现。
- GPU 自动模式保留 CPU 回退，不保证所有外观都使用 GPU；RAW 解码和文件编码仍在 CPU。这些是本地验证结果，不是新发布提交的 CI 结果。
- 原始 RAW、参考照片和模型权重未修改或打包，客户端不增加模型运行时。
