# RawLab Bundled Look Attribution

Status on 2026-10-16: 28 adapted third-party LUTs remain UNCONFIRMED for
redistribution. The repository owner explicitly approved public source
publication with this notice and integration into `development`. That approval
is not a license grant from the original authors or authorization for an
official release. Color adaptation does not grant copyright rights.
`REDISTRIBUTION_BLOCKED.md` retains the unresolved release risk; it does not
block compilation, including Release builds. CI success is not license clearance.

Camera source: u/Aggressive-Win-6351's public share, with ROGER WANG credited in
some source headers. Source and author statements:
<https://www.reddit.com/r/Lumix/comments/1tgii1i/reverseengineering_camera_color_pipelines_instead/>
and <https://drive.google.com/drive/folders/1P6xJW2-x8pFAm6hP8vNdlDe11Pb06DId>.
The camera adaptation explicitly interprets the author's gamma 2.4 statement as
black-zero display BT.709/D65, full range, both input and output. It is a creative
appearance, not a camera calibration or manufacturer-certified match.

Kodak-named source: the G'MIC-labelled Film-Luts snapshot
`af957b631a304e6be94778b96cb3395de3438e9f`,
<https://github.com/YahiaAngelo/Film-Luts>. G'MIC credits Pat David for film groups
and Juan Melara for print films: <https://gmic.eu/color_presets/>. The collection's
MIT text is not treated as a license from the LUTs' underlying authors. The
original tables have no transfer declaration. RawLab's new RGB creative
interpretation uses them directly on neutral display-sRGB, following G'MIC's
ordinary image/direct-RGB workflow; it does not assert the original tables were
authored in sRGB. The 2383/2393 RGB looks are not original Log-input PFE transforms.

EKTAR 100 Phuket v2 Strong is RawLab's separate independently authored look,
licensed with the project (GPL-3.0-only), generated by
`experiments/ektar100-phuket-v2/generate.py`. Its original F-Log2/F-Gamut to
display-sRGB contract and existing artwork are retained byte-for-byte.

The 28 new illustrations are original image_gen concept labels, not official
packaging, a manufacturer endorsement, or LUT-rendered examples. Prompts and
generation provenance are in `Artwork/generated-*.json`; the reused Ektar artwork
record remains in `RawLabMac/Resources/FilmIcons/generated-ektar-100-phuket.md`.
Manufacturer and stock names only identify intended creative looks. Source hashes,
adaptation decisions and sampled error metrics accompany the project source.
