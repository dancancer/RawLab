# Bundled Look Redistribution Is Not Cleared

This snapshot is for the user's explicitly requested local integration and
validation. Do not push, publish, upload, redistribute these adapted third-party
LUTs, or ship an installer containing them until the underlying rights and
required notices have been confirmed. All four clients reject Release builds
while this marker is present. Debug/private validation is not release clearance.

The 28 third-party derivatives have UNCONFIRMED redistribution permission.
Public download, a creator credit, and permission to use a LUT are not assumed
to grant redistribution rights. Adapting the table does not remove those rights.

The independently authored EKTAR 100 Phuket v2 Strong is separate, generated by
`experiments/ektar100-phuket-v2/generate.py` under RawLab's project license. It
uses its existing artwork without replacement. New concept artwork is original
image_gen output, not official manufacturer packaging, endorsement or a LUT
rendered sample. Exact prompts/provenance are retained in `Artwork/`.

Manufacturer/film names identify the intended look only. No manufacturer
authorship, endorsement, measured film calibration or camera equivalence is
claimed. See `docs/luts/README.md` in the project source for the full audit and
the explicit adaptation choices. Remove this marker only after an evidence-based
per-source license review and update all license fields and notices together.
