# RawLab Mac Editor

Mode: Operate.

Photographers compare cross-brand RAW and supported raster photos with film simulations, adjust a selected photo and export it without changing the source. The approved interaction reference is the iOS Photos adjustment experience adapted to a native macOS window, not a mobile-layout clone.

The surface uses a collapsible left directory/thumbnail tree, a central photo workspace, a collapsible upper-right output histogram and a single bottom adjustment area. Film is a peer circular tool beside numeric adjustments, with its cartridge chooser below the shared row. Signed yellow rings encode adjustment direction relative to the default.

Success means a user can add a directory, select a photo, switch films, make precise changes, compare, reset and export. Switching photos must not leak exposure or film settings between photos. Numeric rendering behavior is outside this visual redesign.

Local-only visual evidence, not included in Git: `.impeccable/review/mac-final-empty.jpg`, `mac-final-compact.jpg` and `mac-final-wide.jpg`. Reproduce the views with the app rather than treating these local paths as repository assets. Native SwiftUI/AppKit on macOS; no web detector applies.
