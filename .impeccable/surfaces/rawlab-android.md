# RawLab Android Editor

Mode: Operate. Target audience: sighted photographers working at standard Android text scales across six supported languages (low-vision `fontScale >= 1.3` large-text reflow and TalkBack/screen-reader flows are out of active design scope).

Native Jetpack Compose / Material 3 client using a static dark-only `darkColorScheme` (`background #1C1C1E`, `surfaceContainerLow #212124`, `surface #272729`, `surfaceContainerHigh #303033`, `primary #F2CE48`, `onPrimary #252110`, `secondary #63CDD6`, `onSurface #EEEEF2`, `onSurfaceVariant #B9B9C3`, `outlineVariant #444449`, `error #FFB09B`; no light theme, no Material You dynamic color) with edge-to-edge dark system bars and window insets (`statusBarsPadding`, `navigationBarsPadding`, `imePadding`). State-driven root router in `MainActivity` preserves Album and Editor state across Camera, Batch Export, and Batch Selection routes.

- **Two-Level Dedicated Tool Workspaces & Responsive Dock**:
  - Side dock triggers at `maxWidth >= 600 dp && maxWidth > maxHeight` (`336 dp` fixed width); narrower or portrait layouts use a bottom dock (adaptive `108 dp` 1-row / `164 dp` 2-row home height; `min(332 dp, availableHeight - 96 dp)` tool workspace height). Default photo margin is `0 dp` (`8 dp` toggleable). Minimum touch target `48×48 dp`.
  - **Overview**: `48 dp` `CenterAlignedTopAppBar` (Back/Album, Camera, Export, sectioned More), floating dark translucent `workspaceActions` pills (`CircleShape`, `Black 0.62`, `1 dp` `White 0.14` stroke) above dock (Undo, Redo, `EditorWorkspaceResetControl`, Compare) with raised `comparisonInset` (`64 dp` / `+84 dp`) preventing overlay collision, 4-column `EditorTool` grid (`52 dp` min row height; Looks adds `My Presets`; unavailable tools dim and explain via snackbar), and 6 SDR / 7 HDR `EditorGroupStrip`.
  - **Active Tool Workspace**: Top bar hides; every tool opens a scoped `AdjustmentDraft` (100 undo/redo steps) with scrollable controls, `workspaceActions` focus fade + `workspace-more` menu (matching Camera, My Presets, Info, Histogram, HSL Target, Fine, Compare Mode, Pure Preview, Processing Settings) + tappable yellow `Fine` pill (`adjustment-fine-badge`) between capsules when active, and a fixed `48 dp` `Close / Title / Check` Apply/Cancel footer (`Check` in `#F2CE48` when dirty). Predictive Back (`enableOnBackInvokedCallback="true"`) prompts Apply / Discard / Continue on dirty exit. Per-photo HDR controls (`HDR Editing`, `HDR Rendition`, `HDR RAW`) live inside Photo Processing Settings, leaving Editor Settings strictly app-wide.
- **Controls, Curves, Grading, HSL & Lens**:
  - `AdjustmentRuler` (`48 dp` tall): standard 21-tick fixed track (`onSurfaceVariant` baseline dot, `#F2CE48` current needle and active delta bar, `+4 dp` proximity pulse suppressed when `ANIMATOR_DURATION_SCALE == 0`, `24 dp` horizontal edge-back guard, `125 ms` haptics) on single-param tools; compact single-row inline sliders (`14 dp` circular thumb, fixed `56/68 dp` readout width) on multi-param tools. Modified values tint in `colorScheme.primary` (`#F2CE48`) and use fixed-decimal signed `formatAdjustmentReadout` formatting (`+0.10`, `-0.05`, `0.00`, `+12`). Denoise and Photo Effects rely on canvas Reset without duplicate inline headers/reset buttons, and auxiliary vignette/grain parameters remain editable ahead of setting amount (except vignette highlight protection requiring negative amount). Tapping monospace readouts opens a validated Material numeric `AlertDialog`.
  - Includes RGB/R/G/B `CurveCanvas` (`194 dp`), 3-zone `GradingWheel` (`130 dp`), 8-channel `19 dp` HSL swatches + `88 dp` `3×` circular photo-sampling loupe, live `GeometryCropCanvas`, **RAW + JPEG Lens Correction** (including `Vignetting` toggle & manual metadata dialog; disabled on normal X3F and HDR), Quick/My Presets, Copy/Paste/Sync, and v3 migration/rollback in Processing Settings.
- **HDR, 1:1 ROI Zoom, Album, Batch & Camera**:
  - API 34+ FP16/scRGB HDR preview (explicit SDR fallback) with top-end `HDRMonitoring` card, False Color, EV luminance histogram, `.hdrRendition` controls, and cancellable `HDR_JPEG` export progress. Above `1.05×` base scale, renders a `1024 px` multi-level ROI tile pyramid synchronized across comparisons.
  - `AlbumScreen` provides Square or Staggered grids (`1–6` cols, default `3`), `All / Edited / Unedited` segmented filter, lower-right `4 dp` edited pencil badge, and Android 14+ partial access handling. Settings exposes manual cleanup for System Open With/Share copies and exported camera originals.
  - `CameraScreen` (`HOME` / `CONNECT` / `HELP` / `IMPORT` / `TETHER`) provides Sony BLE/Wi-Fi + manual Wi-Fi connection (model-agnostic capability probing, verified with α7C II fw 2.00; initial ZV-E10 profile), manual & one-tap resumable incremental import (local JPEG resize/recompress), and tethered live view (`68 dp` shutter, `16 sp` 4-slot parameter strip, 14 focus areas, `640×480` tap-to-focus, `#34D759` locked focus frames, Cancel Focus pill).
