# Color grading v1 数值合同

状态：v1 CPU 数值与固定质量集已准入；GPU 对照、四端 UI 和整体迭代验收分别登记。
这是 RawLab 的算法，不对应 Adobe 的私有数值映射。

## 参数与顺序

三个区按 shadows、midtones、highlights 排列，各有 hue `[0,360)` 度、saturation `[0,100]`。
UI 的 360 度等价于 0，进入存储/交换/核心前归一化；非法/非有限配置整体拒绝。
默认六值为 0；全部 saturation=0 时直接返回原像素，不执行传递函数或限幅。
非零 hue 与零 saturation 是合法的待用颜色，必须保存在 native record/payload/history 中。

阶段位于 legacy HSL 后、chroma denoise 前。输入/输出是 display-encoded sRGB，
只在本阶段内部转为 display-linear sRGB，不改变 RAW 解码、WB、曝光、LUT 或旧 tone 顺序。

## 传递函数与固定权重

每通道解码：`D(x)=x/12.92`（`x<=0.04045`），否则 `((x+0.055)/1.055)^2.4`。
编码：`E(x)=12.92*x`（`x<=0.0031308`），否则 `1.055*x^(1/2.4)-0.055`。
负工作值继续线性分支，正超白值继续幂函数；不在进入本阶段时硬截断。
沿用既有 sRGB 标准舍入常数，其分段交点的理论接缝小于 `3e-8` 编码值，包含在
下文误差门槛内；不另改传递函数常数。identity 必须返回原像素，不能靠往返转换实现。

线性亮度使用差值形式 `Y=G+0.2126*(R-G)+0.0722*(B-G)`，灰阶亮度严格等于通道值。
令 `S(t)=t²*(3-2t)`，先将 t 限于 `[0,1]`，固定原始权重为：

```text
ws = 1 - S((Y-.20)/.35)
wm = S((Y-.20)/.30) * (1-S((Y-.50)/.30))
wh = S((Y-.45)/.35)
w = (ws,wm,wh)/(ws+wm+wh)
```

区间定义在线性亮度上，不按当前照片直方图移动。三个区平滑重叠、权重非负且归一；
低于 .20 只有阴影、高于 .80 只有高光，中间调在 .50 占主导。没有硬阈值选区。

## 色度、强度与色域

把每区 hue 转为 `HSV(h,1,1)` 的单位 RGB 方向 `u`，在 display-linear RGB 中使用
`d=(u-Y(u))*(saturation/100)`。此向量亮度为零；三个区的 d 只按配置预计算一次。
对每个像素，混合位移为：

```text
a = clamp(Y,0,1)
delta = a*(1-a) * (ws*ds + wm*dm + wh*dh)
```

幅度 `a*(1-a)` 最大为 .25，黑白端点为 0，避免端点着色与阴影噪声的固定增益。
若 delta 为零则精确返回原像素。

输出沿同一亮度中心收敛，不逐通道裁掉不同色度：令 `c=(R-Y,G-Y,B-Y)+delta`，
`lo=min(0,R,G,B)`、`hi=max(1,R,G,B)`，选择最大的 `k∈[0,1]`，使每个
`Y+k*c` 在 `[lo,hi]`，然后编码回 sRGB。实现仅在最终浮点舍入时限于上述边界。
逐通道约束为：`c>0` 时 `(hi-Y)/c`，`c<0` 时 `(lo-Y)/c`，`c==0` 时无约束；
k 取 1 和所有约束的最小值，CPU/GPU 不增加各自的 epsilon 分支。

SDR 输入的 lo/hi 固定为 0/1，因而输出保持 SDR 有界和线性亮度。若旧 contrast/HSL
已有越界值，边界扩为其已有极值，避免微小 saturation 突然裁掉原工作值；此阶段不
扩大已有通道极值，后续输出编码继续负责最终 SDR 限幅。边界由 min/max 连续变化，
不在某通道跨过 0 或 1 时突然更换算法。

## 冻结门槛

- 全零 saturation（含待用 hue）逐字节 identity；黑白端点不凭空染色。
- 固定 binary64 向量，CPU/GPU 每通道绝对误差 ≤5e-6；RGB8 同尺寸差异 ≤2 DN。
- 10001 点权重/灰阶梯度无硬分区跳变；359.999→0 色相连续；单区修改不影响其零权重区。
- SDR 21³ 色块网格有限/有界，解码后亮度绝对差 ≤4e-6；越界输入和接近零强度的输出连续。
- 五张固定真实照片包含人像、天空、饱和结构、暗部纹理和高 ISO 噪声；FINAL 匹配尺寸
  与 100% 局部检查颜色过渡、轮廓、肤色结构和噪声。颜色分级允许主动染色，不能用
  “保持原肤色”拒绝预期调色，也不能因能染色就忽略色带/硬边。

数值与真实质量记录均通过后才冻结；实际四端 UI 和 IT-07/15 另行验收。
