# 基础调节 v3

`rawlab/3/standard` 改善普通 SDR 编辑的基础调节响应。它使用独立实现的局部亮度处理和
连续曲线，参考 Lightroom Classic 15.5.1 的实际导出响应；不是 Adobe 私有算法的复刻，
也不承诺跨相机 profile、RAW 解码与默认外观的逐像素一致。版本 1、2 的公式保持冻结。

## 参数与顺序

客户端普通曝光为 `[-5,5] EV`，核心仍以 `2^EV` 乘在线性 RGB 上。其他九个基础滑杆
保持 `[-100,100]`；核心高光的符号仍由客户端取反，v3 内部恢复为正值提亮。
饱和度继续使用原来的亮度与色差混合，最低值完全去色。HDR 使用独立渲染及范围契约。

1. RAW 解码、降噪、白平衡、曝光保持原顺序；去马赛克与 C5 沿用版本 2。
2. 高光和阴影在进入 neutral/film look 前改变局部照明基底，三个通道使用共同增益。
3. 外观之后依次为去朦胧、黑白场、现有曲线、对比度、饱和度、鲜艳度、HSL、颜色分级。
4. 显示降噪之后处理清晰度，再进行原有锐化、效果、几何和最终缩放。

所有新增控制在零值时直接旁路；不先截断负通道或线性超白值。显示输入沿既有逆 sRGB
路径进入工作空间，不获得 RAW 传感器余量。已经被输入或外观裁掉的信息无法恢复。

## 响应模型

- **高光、阴影**：使用 `log2(Y/0.1845)`，分析最长边最多 768 像素。面积加权采样与
  引导滤波估计局部照明，半径为分析最长边的 2.5%，正则量为 `0.25 EV²`。
  平滑区域权重分别覆盖暗部与亮部；共同增益为
  `2^(3.5*shadows*shadowWeight + 3*highlights*highlightWeight)`。
  最大系数不是滑杆固定对应的 EV，实际增益由该像素的区域权重决定。
- **对比度**：在显示域使用 `x^g / (x^g + (1-x)^g)`，其中 `g=2^(0.75*amount)`。
  黑、白和中点固定，最低对比度仍保留明暗层次；扩展工作值不在此处截断。
- **黑白场**：负黑场采用输入端点的仿射映射，正黑场使用随亮度变化的输出端点；
  白场使用连续亮度增益。控制覆盖较宽明暗区域，最终输出阶段才按 SDR 契约裁剪。
- **鲜艳度**：负端保留部分原有色差；正端优先增加低饱和颜色，并保留肤色保护和色域边界。
  完全去色由饱和度负责。
- **清晰度**：在线性亮度的平方根域估计局部残差，以共同 RGB 增益调整局部对比度。
  正端系数 1.36，负端 `-0.8*(-amount)^0.75`；保留暗部、高光和色域保护。
- **去朦胧**：保留暗通道与空气光估计，v3 透射率下限为 0.2；调整保护权重及负端
  雾化强度。它仍是独立近似算法，不能视为 Lightroom 的透射率或空气光实现。

Lightroom 的响应会随图像内容变化。尤其白场正端、阴影和去朦胧不能由一条固定曲线
概括；当前实现不对所有图像承诺相同误差。后续标定应同时检查亮度、颜色、局部对比度、
高光余量及暗部噪声，不能只用整图 RGB 误差选择强度。

## 后端、预览与兼容

新增高光/阴影、对比度、黑白场、鲜艳度以及非零氛围控制使用 CPU。
GPU Auto 返回完整 CPU 路径；Force 明确返回 unsupported。未启用这些控制时，
已有曝光和饱和度 GPU 路径不变。未执行的移动 GPU 或 Windows 硬件验证应单独列明。

高光/阴影与氛围控制需要邻域信息。FINAL、文件导出和默认精确预览使用完整源图，
仅显式启用的 viewport PREVIEW+BUFFER 可使用缩小工作图，并保留全源分析尺度。
去朦胧缓存包含处理版本；版本切换不能复用另一版本的分析结果。

新建编辑采用 v3。旧编辑先使用原身份显示，再按[自动迁移契约](processing-migration.md)
尝试换算；误差超限保留旧版，成功迁移保存完整旧设置供回退。手动切换版本保留滑杆数值，
不保证外观不变，也不能替代自动迁移的参数换算与验收。
